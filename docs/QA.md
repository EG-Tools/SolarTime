# v0.13 검증 범위

## 확인 대상

카메라 좌/우클릭 공통 메뉴, 저장·삭제 취소와 단축키, 오른쪽 단일 감상 토글, 초 표시와 라벨 자동 정리 기본값/저장, 256배 확대 및 기존 64배 이하 시점 호환성, 내장 텍스처 경계 보정, 수동/자동 카메라 결과의 소유권 검사, 탭 숨김/복귀 시 프레임·캐시 유지, 모바일 팝업/도구 위치를 검증했습니다.

회귀 검사 결과는 `release-verification-v0.13.json`, 개별 결과는 `refinements-*-v0.13.json`, `unit-results-v0.13.txt`에 기록합니다.

## 실행 환경과 제한

Linux headless Chromium + Python Playwright. 이 환경의 localhost 탐색은 `ERR_BLOCKED_BY_ADMINISTRATOR`를 반환하여 소스/생성 HTML을 `set_content`로 주입해 실행했습니다. 브라우저 저장소는 opaque origin에서 사용할 수 없어 명시적인 테스트 어댑터로 검증했습니다. Windows 더블클릭, 실제 브라우저 origin 간 저장 유지, 실제 마우스 하드웨어는 직접 검증하지 못했습니다.

WebGL을 사용할 수 없어 표면/배경은 CPU 호환 렌더러에서 실행됐습니다. 실제 GPU 드라이버에서 이음선과 화질이 동일한지는 확인하지 못했습니다. GPU 샘플링 설정의 코드·공통 재질 처리와 1024 출력 상한은 회귀 검사했습니다. 원본 지도를 새로 다운로드한 테스트는 이번 변경 범위에 포함하지 않았으며 내장 데이터와 기존 로컬 캐시/수신 공통 처리 경로를 사용했습니다.

탭 전환은 visibility 상태/이벤트를 주입해 수명주기를 검사했습니다. 실제 Chrome 탭의 compositor·GPU context 재활성화는 별도 실기기 확인 대상입니다. 유지할 메모리는 기존의 픽셀 수 제한을 따릅니다. 숨겨진 동안 새 표면 작업을 제출하지 않고 진행 중인 한 묶음만 완료하도록 제한합니다.

320×568 화면에서 새 모드 토글이 재생 카드에 가려지던 문제를 발견하여 짧은 휴대폰의 도구 위치를 위로 조정했습니다. `elementFromPoint`와 실제 버튼 클릭으로 가림이 사라진 것을 재검증했습니다.

이번 패키지는 저장소나 공개 사이트를 변경하지 않습니다.
