# Solar Time v0.01 검증 기록

## 실행한 검증

`node --test tests/astro.test.cjs`: **18개 테스트 통과**.

케플러 방정식 수렴, J2000 기준 시각, 지원 날짜 범위의 유한 좌표, 지구의 J2000 위치, 행성 중심과 궤도 좌표식의 일치, 타원 궤도 폐합, 근일점·원일점 거리, 달의 지구 중심 궤도, 위상 수치 범위, 실제 시간·배속·일시정지·재개·속도 전환 연속성·날짜 경계를 확인했습니다.

`python tests/browser_test.py`: **41개 확인 항목 통과**. 결과는 `browser-results.json`에 있습니다.

Linux Chromium의 1648×928 데스크톱과 390×844, DPR 2 모바일 화면을 사용했습니다. 단일 HTML 전체를 페이지에 주입해 오프라인으로 렌더링했습니다. 화면을 직접 확인하고 키보드·마우스·터치 탭, 날짜 선택, 각종 설정과 감상 모드를 검사했습니다. 외부 네트워크 요청과 JavaScript 런타임 오류는 없었습니다. 별·태양까지 일시정지되는 것과 태양 효과를 껐을 때의 텍스처 고정도 검사했습니다.

검사 환경의 데스크톱 측정은 약 60 FPS였습니다. 이는 해당 환경의 단시간 측정치이며 사용자 PC의 성능을 보장하지 않습니다.

소스 JavaScript 3개 파일에 `node --check`를 실행했습니다. 단일 HTML은 같은 소스에서 생성했습니다.

## 검증 범위의 한계

환경 정책상 브라우저의 `file://` 및 HTTP 탐색이 차단되어, Playwright의 `set_content`로 단일 HTML을 로드해 검사했습니다. Windows에서 실제 파일을 더블클릭하는 동작, 실제 모바일 기기, 모든 브라우저, GitHub Pages 배포는 직접 검증하지 않았습니다. 런타임 파일은 외부 요청 없이 실행되도록 구성했습니다.

두 손가락 제스처 처리 코드는 포함되어 있지만 실제 하드웨어의 멀티터치 제스처는 검사하지 않았습니다. 전체 화면은 브라우저 권한에 따라 거절될 수 있으며 그 경우 메시지를 표시합니다.

궤도 테스트는 수학적 일관성과 알려진 기준값에 대한 회귀 검사입니다. JPL Horizons와 전 시점 비교한 정밀 천문력 검증이 아닙니다. 달·명왕성·축척·고리·표면은 README에 명시한 단순화와 시각적 조정을 포함합니다.

GitHub 저장소는 읽기 도구로 빈 상태를 확인했지만, 현재 연결에 파일 쓰기·커밋 도구가 없어 이 배포본을 원격 저장소에 반영하지 않았습니다.
