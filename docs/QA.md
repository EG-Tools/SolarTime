# Solar Time v0.12 검증

단위 테스트 **114/114**, 고유 브라우저 확인 항목 **65/65**를 통과했습니다.

- 기존 버튼을 옮긴 단일 세로 조작부와 확대·축소·기본 시점·번호·좌우 회전 순서.
- 초당 2° 회전, 방향 반전, 정지, 시점/확대/추적 유지, 공전 배속·정지 독립성.
- 실제 카메라 프레임 속도 차이에 관계없는 경과 시간 계산과 360° 연결.
- 자동 회전 중에도 고해상도 표면 프레임이 계속 수신되는지 확인.
- 기존 저장 확인·삭제 확인·단축키 부드러운 이동, 저장 스키마 유지.
- 감상 모드에서 전체 조작부와 모드 아이콘만 활동 중 표시, 1.8초 유휴 숨김, 서울 표시.
- 감상 모드에서도 저장/삭제 팝업 유지, 확인창이 열려 있을 때 숨김 보류.
- 가만히 클릭해 깨우는 동작은 회전을 유지하고 실제 드래그는 회전을 중단.
- 1648×928, 390×844, 320×568, 844×390 화면의 조작부 정렬·경계·터치.
- 새 실행본을 다시 저장할 때 버전·제목·단일 조작부가 유지되는지 확인.

환경: Linux headless Chromium 144.0.7559.96, 오프라인 HTML 주입. WebGL 비활성 환경의 CPU 호환 경로로 확인했습니다. 실제 하드웨어 GPU, Windows 파일 더블클릭 실행, 외부 사진 수신은 검증하지 않았습니다. 저장소와 visibility 이벤트는 명시적 테스트 어댑터를 사용했습니다.

한 번에 실행한 브라우저 명령은 31개 검사를 완료한 뒤 실행 제한으로 종료됐습니다. 남은 데스크톱·모바일 범위와 마지막 입력 경계는 별도로 실행했습니다. 보고서의 합계는 검사 이름을 기준으로 중복을 제외했습니다.

재검증: `npm test`; `npm run build`; `python tests/orbit_controls_browser.py`. 실행 시간이 제한된 환경에서는 `SECTION=core`, `SECTION=remaining`, `SECTION=mobile`로 나눌 수 있습니다.

이미지 자산, `src/assets.js`, 천문 계산, 배경·혜성 코드는 v0.11과 바이트 단위로 동일합니다. 태양 샤인과 표면 셰이더 계산을 변경하지 않았습니다. 표면 작업 수신에는 자동 카메라의 제한된 중간 프레임 정책만 추가했습니다.

GitHub 및 공개 웹사이트는 이번 작업에서 변경하지 않았습니다.
