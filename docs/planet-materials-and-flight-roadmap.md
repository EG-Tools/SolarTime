# 행성 재질·고리 파티클·우주선 비행 모드 장기 로드맵

상태: 계획 단계. 아직 구현하거나 배포하지 않았다.

## 목표와 기준

- 로컬 참고 영상: `planets3x3_pluto_colorMercury_axis_tilt_1080p.mp4`
- 여행 효과 참고 영상: `Honeycam 2026-09-30 05-08-05.mp4`
- 영상에 표시된 NASA/관측 자료의 분위기와 행성별 특징을 참고하되, 실제 제품용 텍스처를 추가하기 전에는 원본 출처와 이용 조건을 다시 기록한다.
- Astra 홈페이지는 비행 중 카메라 주변을 흐르거나 소용돌이치는 파티클의 분위기만 참고한다.
- Astra처럼 마우스 위치에 반응하는 상호작용은 구현하지 않는다.
- 여행 참고 영상처럼 화면 전체가 긴 속도선으로 가득 차는 워프 효과는 사용하지 않는다. 입자 수, 밝기, 선 길이를 크게 줄여 Solar Time의 차분한 화면을 유지한다.
- 새 행성별 옵션은 기존 원칙대로 각 행성 카드의 최하단에 배치하며, 설정값은 저장·복원·초기화를 지원한다.

## 기능 범위

### 1. 화성 대기와 금성 대기층

#### 화성

- 현재 화성 지표 텍스처를 기본 표면으로 유지한다.
- 별도 대기 이미지를 덧씌우기보다 얇은 대기 림과 연무를 셰이더로 만든다.
- 멀리서는 대기 가장자리가 보이고, 카메라가 가까워질수록 대기 농도를 낮춰 지형이 선명해지게 한다.
- 거리 변화 중 대기가 갑자기 켜지거나 꺼지지 않도록 넓은 전환 구간을 사용한다.

#### 금성

- 카드 옵션 이름은 `대기층`으로 한다.
- 100%에서는 현재의 두꺼운 구름·대기 모습을 유지한다.
- 0%에서는 Magellan 계열 레이더 지형 텍스처가 보이게 한다. 이는 사람 눈으로 본 실제 지표색이 아니라 레이더 기반 지형 표현임을 도움말에 밝힌다.
- 현재 프로젝트에는 금성 대기 텍스처만 있으므로, 승인된 지표 원본을 확보해 256/512/1024/2048/4096 단계로 추가해야 한다.
- 표면과 대기층을 하나의 셰이더에서 혼합하고, 기본값은 100%로 한다.

### 행성별 대기 회전 기준

아래 수치는 사용자가 제공한 장기 구현 기준이다. 실제 배포 단계에서는 NASA 등 1차 자료로 수치와 기준 고도를 다시 확인하고 출처를 기록한다.

#### 지구

- 하나의 전역 회전 배율을 사용하지 않는다.
- 저위도 구름은 지표 자전의 약 0.9배, 중위도 구름은 약 1.1배로 이동시킨다.
- 고위도는 현재 1.0배로 두며 각 위도 구간은 부드럽게 이어지게 한다.
- 구름 덩어리는 생성 당시의 위도를 기준으로 상대속도를 유지해 한 구름 안에서 절단선이나 전단 경계가 생기지 않게 한다.

#### 금성

- 금성 지표 자전 주기는 약 243일, 상층 황산 구름대의 회전 주기는 약 4일을 기준으로 한다.
- 고도 약 50~70km의 상층 구름은 약 360~400km/h로 이동하며, 지표보다 약 60배 빠른 초회전 대기로 취급한다.
- 셰이더에서는 단순히 지표 위상을 복제하지 않고, 관측된 약 4일 구름 회전 주기를 별도 대기 위상으로 계산한다.
- 대기층 슬라이더 0%에서는 구름 위상 계산과 구름 텍스처 처리를 생략하고 지형만 표시한다.

#### 토성

- 내부 자전은 약 10시간 33분, 적도 기준 약 35,500km/h를 기준으로 한다.
- 적도 구름은 약 37,300km/h, 내부 자전에 더해지는 상대 풍속은 약 1,800km/h로 본다.
- 적도 구름 회전은 내부 자전의 약 1.05배를 초기 시각 기준으로 사용한다.
- 토성의 위도별 줄무늬와 제트기류를 표현할 때는 지구·금성과 같은 공용 대기 이동 구조를 재사용하되, 토성 전용 위도 속도 프로필을 별도 설정으로 둔다.

#### 공용 구현 원칙

- 공용 대기 셰이더는 행성별 `기준 회전 주기`와 `위도별 상대속도 프로필`을 데이터로 받도록 확장한다.
- 자전 위상이 한 바퀴마다 1에서 0으로 되감길 때 구름이 틱하며 재배치되지 않도록, 구름 이동은 수명 또는 연속 시각에서 직접 계산한다.
- 프레임마다 값을 누적 저장하지 않으며 현재 시뮬레이션 시각으로부터 위치를 계산한다.
- 지구에서 해결한 부드러운 생성·소멸, 절단면 제거, 야간 불빛 가림 구조를 금성과 토성에도 공유한다.

### 2. 토성 고리와 얼음·먼지 파티클

- 현재보다 고리의 밀도 차이와 빈 공간이 드러나도록 알파 분포를 다시 조정한다.
- 특히 고리 중간 일부가 균일한 띠처럼 보이지 않게 밀도를 낮추고 세부 띠를 보강한다.
- 카메라가 고리에 가까워질 때만 얼음·먼지 파티클이 서서히 나타나게 한다.
- 카드 최하단에 `고리 파티클` 0~100% 슬라이더를 둔다.
- 0%에서는 파티클 렌더링을 완전히 생략한다.
- 랜덤 크기의 큰 돌, 작은 바위, 미세한 먼지 세 종류만 단순하게 섞어 고리 평면 주변에 배치한다. 복잡한 충돌이나 입자 간 물리는 구현하지 않는다.
- 100%에서도 무조건 10,000개를 그리지 않는다. 우선 가까운 화면에서 수백~약 1,500개가 보이는 가벼운 상한으로 시작하고, 실제 화면이 비어 보일 때만 성능 측정 후 늘린다.
- 큰 돌은 소수의 단순 저면체 또는 빌보드, 작은 바위와 먼지는 공용 인스턴스 버퍼로 처리한다. DOM 객체나 개별 드로우 호출은 사용하지 않는다.

### 3. 천왕성 고리 파티클

- 토성에서 만든 공용 고리 파티클 엔진을 재사용한다.
- 천왕성의 좁고 어두운 고리 폭, 색, 밀도 분포만 별도 설정한다.
- 카드 최하단에 별도의 `고리 파티클` 0~100% 슬라이더를 둔다.
- 토성 기능 뒤에 구현하면 추가 작업량은 비교적 작다.

### 4. 지구 구름 농도

- 지구 카드 최하단에 `구름` 0~100% 슬라이더를 둔다.
- 기본값은 100%이며, 0%에서는 구름 레이어가 보이지 않게 한다.
- 직접 GPU 렌더러, 작업자 렌더러, CPU 호환 렌더러에서 같은 값이 적용되어야 한다.
- 야간 불빛을 가리는 구름 효과에도 같은 농도를 반영한다.
- 기존 구름 텍스처와 셰이더 경로가 이미 있어 가장 먼저 구현하기 적합하다.

### 5. 우주선 자동 여행 모드

- 랜덤 회전 버튼 아래에 UFO 아이콘 버튼을 추가한다.
- 선택된 천체가 있으면 그 천체부터 시작하고, 없으면 현재 카메라에서 가장 가까운 적절한 천체부터 시작한다.
- 한 천체를 한 바퀴 감상한 뒤 현재 위치에서 다음으로 가까운 천체로 이동하고, 같은 과정을 무한 반복한다.
- 주요 위성 및 명왕성은 해당 표시 옵션이 켜져 있을 때만 경로에 포함한다.
- 태양과 대형 행성에서는 충돌과 과도한 궤도 반경을 피하도록 천체별 안전거리를 둔다.
- 시작 전 카메라 상태를 저장하고, 모드 종료 시 원래 시점으로 복귀할 수 있게 한다.
- 사용자가 직접 카메라를 조작하거나 다른 천체를 선택하면 자동 여행을 자연스럽게 중단한다.

#### 여행 파티클

- 파티클은 월드 전체가 아니라 카메라 주변의 제한된 공간에 생성한다.
- 데스크톱 기본은 약 80~250개의 성긴 입자로 시작한다. 화면 중심을 가리지 않고 가장자리와 카메라 옆을 주로 지나가게 한다.
- 평상시에는 작은 점이나 짧은 먼지 형태로 보이고, 천체 사이를 빠르게 이동할 때 일부만 짧게 늘어나게 한다.
- 이동 속도에 따라 흐름, 짧은 선 길이, 약한 소용돌이만 달라지게 한다. 참고 영상의 긴 방사형 속도선과 강한 화면 번쩍임은 제외한다.
- 고정 시드를 사용해 깜빡임을 막고, 카메라와 함께 재배치해 무한히 이동하는 느낌을 만든다.
- 클릭·마우스 이동에는 반응하지 않는 순수 시각 효과로 구현한다.
- 비활성화 상태에서는 업데이트와 드로우 작업을 하지 않는다.

## 권장 구현 순서

1. 지구 구름 농도 — 기존 렌더링 경로에 값 하나를 연결하는 작업이라 가장 쉽다.
2. 화성 대기 — 새 텍스처 없이 셰이더와 거리 전환을 추가할 수 있다.
3. 금성 대기층 — 새 지표 자산과 LOD 등록이 필요하다.
4. 토성 고리 밀도 및 공용 고리 파티클 엔진 — 시각 조율과 성능 검증이 필요하다.
5. 천왕성 고리 파티클 — 토성 엔진을 재사용해 확장한다.
6. 우주선 자동 여행 모드와 여행 파티클 — 카메라 상태, 천체 순회, 취소 동작까지 연결해야 하므로 가장 어렵다.

사용자가 제시한 다섯 항목만 묶어서 난이도를 비교하면 `4 → 1 → 2 → 3 → 5` 순서다. 다만 3번은 2번의 공용 엔진이 완성된 뒤에는 매우 작은 후속 작업이 된다.

## 성능 원칙

- 추가 4K 금성 지표는 금성을 선택하거나 가까이 갈 때만 불러온다.
- 고리와 여행 파티클은 화면 투영 크기와 카메라 거리에 따라 단계적으로 활성화한다.
- 파티클은 안정적인 고정 시드를 사용해 원거리 및 가장자리 깜빡임을 막는다.
- 모바일과 낮은 자동 품질 단계에서는 최대 입자 수를 낮추고, 필요하면 여행 모드는 데스크톱 우선 기능으로 제공한다.
- 슬라이더 0%는 단순히 투명하게 그리는 것이 아니라 해당 렌더링 작업을 생략한다.
- 새 카드 문구와 도움말은 지원 중인 13개 언어에 추가한다.

## 완료 확인 항목

- 새 슬라이더의 값이 새로고침 뒤에도 유지되고 설정 초기화 시 기본값으로 돌아온다.
- 가까이 가거나 멀어질 때 대기와 파티클이 튀지 않고 부드럽게 변한다.
- 토성·천왕성 고리가 원거리에서 깜빡이지 않는다.
- 파티클 100%에서도 카메라 조작 지연과 프레임 급락이 허용 범위 안에 있다.
- 자동 여행 시작·중단·복귀가 저장된 카메라와 행성 추적 기능을 깨뜨리지 않는다.
- 직접 GPU, 작업자 GPU, CPU 호환 경로에서 지구 구름 설정이 일관되게 보인다.
