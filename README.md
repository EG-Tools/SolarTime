# Solar Time

**우주 속 한순간**

Solar Time은 현재 시각과 태양계 천체의 움직임을 한 화면에 담은 웹 기반 태양계 시계입니다. 일이나 공부 중 잠시 쉬면서 우주를 감상할 수 있는 화면보호기형 웹 앱으로 만들어졌습니다.

잔잔한 배경음악과 함께 행성과 주요 위성을 살펴보고, 카메라를 움직여 나만의 우주 풍경을 만들 수 있습니다.

**실행:** [https://solartime.app/](https://solartime.app/)

## 주요 기능

- 현재 시각과 선택한 지역의 현지 시각 표시
- 행성, 달, 유로파, 명왕성의 움직임과 자전 표현
- 고해상도 천체 텍스처와 지구 야간 불빛
- 천체 추적, 자유 카메라, 저장된 카메라 시점
- 실시간부터 장기 시간 여행까지 가능한 시뮬레이션
- 달·유로파의 일식과 행성 정렬 탐색
- 배경음악과 인터페이스를 숨기는 감상 모드
- 알람과 Windows 예약 종료

예약 종료는 별도의 Windows 보조 모듈이 필요합니다. 모바일에서도 기본 기능을 사용할 수 있지만, 넓은 화면과 마우스·키보드를 사용하는 데스크톱 PC 환경에 최적화되어 있습니다.

## 기본 조작

| 입력 | 동작 |
|---|---|
| 마우스 왼쪽 드래그 | 카메라 회전 |
| 마우스 오른쪽 드래그 | 카메라 전진·후진 |
| 마우스 가운데 버튼 드래그 | 화면 이동 |
| 마우스 휠 | 줌인·아웃 또는 전진·후진 |
| `←` `→` | 이전·다음 천체 선택 |
| `↑` `↓` | 연속 줌인·아웃 |
| `Enter` | 선택한 천체 추적·복귀 |
| `0` | 기본 카메라 |
| `1` `2` `3` | 저장된 카메라 |
| `Space` | 시뮬레이션 일시정지·재생 |
| `R` | 실제 시간으로 복귀 |
| `F` | 전체 화면 |
| `H` | 감상 모드 |

앱 안의 도움말에서 더 자세한 조작 방법을 확인할 수 있습니다.

## 천문 계산의 범위

Solar Time은 태양계의 움직임을 감상하고 시간의 흐름을 탐색하기 위한 시각화 프로그램입니다. 관측, 항법, 우주 임무 또는 정밀한 일식 예측에 사용하는 천문력이 아닙니다.

행성 위치는 현재 시대에 NASA/JPL 근사 공식을 우선 사용하고 장기 범위에는 별도의 근사 모델을 적용합니다. 달, 유로파와 명왕성은 각각의 전용 모델을 사용하며, 기준 날짜들은 NASA/JPL Horizons 자료와 자동 검사로 비교합니다. 화면상의 천체 크기와 궤도 간격은 보기 쉽게 조정될 수 있습니다.

## 브라우저와 개인정보

최신 Chrome과 Edge를 권장합니다. 첫 실행에서는 브라우저 언어와 시간대를 바탕으로 언어와 지역을 자동 선택하며, 사용자가 언제든 수동으로 변경할 수 있습니다.

분석 및 광고 관련 기능은 사용자의 쿠키 선택을 따릅니다. 자세한 내용은 [개인정보처리방침](https://solartime.app/privacy.html)에서 확인할 수 있습니다.
