# Solar Time

**Life User · v0.15 · Lyrikey@Naver.com**

실제 기기 시각으로 움직이는 감상용 태양계 시계입니다. 탭 제목은 Solar Time입니다. 위치·자전은 로컬 계산이며 내장 이미지와 배경은 오프라인으로 동작합니다. 관측·항법용 정밀 천문력이 아닙니다.

## v0.15

천체 추적·특징 보기·기본 시점·저장 시점의 카메라 이동을 한 전환 처리기로 통일했습니다. 휠·버튼·드래그·핀치·각도 조작은 짧게 보간하며, 이동 도중 다른 명령도 현재 위치에서 이어집니다. 기존 시점 저장 키와 데이터 형식은 유지했습니다.

1·2·3은 감상 모드·전체 화면·팝업·입력란에서도 저장 시점을 호출합니다. 숫자패드도 지원합니다. 숨겨진 달·명왕성의 저장 시점은 해당 천체 표시를 켭니다. 입력란의 숫자 입력과 브라우저의 Ctrl/Alt/Meta 조합은 유지합니다.

F는 전체 화면 토글입니다. ESC는 감상 모드 → 전체 화면 → 대화상자/패널 순서로 해제합니다. 전체 화면+감상 모드일 때 첫 ESC에서 전체 화면을 유지하려면 브라우저의 ESC 키보드 잠금 지원·허용이 필요합니다. 미지원/거부 시 브라우저 기본 종료가 우선할 수 있습니다. ESC 길게 누르기 등 강제 탈출은 유지합니다. F11과 운영체제 창 최대화는 별개입니다.

선택한 어두운 우주 이미지의 가스 연결부와 구면 경계를 보정했습니다. 결과는 4096×2048 무손실 WebP이며, 2048 원본과 이전 보정 미리보기를 사용한 확대·보정본입니다. 새 4K 관측 사진이 아닙니다.

## 실행·업데이트

GitHub Pages는 루트 `index.html`을 사용합니다. v0.15 변경 ZIP의 **내용물을 기존 SolarTime 프로젝트 루트에 덮어쓰고 GitHub에 올리면** 적용됩니다. 이번 배포는 기존 `src/assets.js` 다음에 배경 전용 `src/sky-asset.js`를 읽으므로 **웹 버전 업데이트에 별도 빌드는 필요 없습니다.**

단일 파일 실행은 Node.js 18 이상에서 `npm run build` 후 `dist/Solar-Time_v0.15.html`을 열면 됩니다. npm install은 필요 없습니다. 빌드는 기존 행성 자료를 포함하고 배경은 한 번만 넣습니다. 기존 dist의 과거 버전은 유지합니다.

배경을 나중에 직접 교체할 때는 `node tools/pack_assets.cjs` 또는 `npm run build`로 이미지와 JavaScript 묶음을 함께 갱신하세요. ‘이미지 포함 HTML 저장’은 실제 수신한 공개 사진과 현재 배경을 함께 저장합니다.

## 조작

좌클릭 드래그: 회전. 가운데 버튼 드래그: 상하좌우 ±20% 이동. 휠·+/−·핀치: 확대/축소. 천체 더블클릭·가까이 보기: 부드러운 추적. 0: 기본 시점. 1·2·3: 저장한 시점. H: 감상 모드. F: 전체 화면. ESC: 감상 → 전체 화면 → 패널 해제. Space: 시뮬레이션 정지/재생. R: 실제 시간 복귀.

오른쪽 숫자 버튼은 좌·우클릭 모두 적용/저장/삭제/취소 팝업을 엽니다. 저장은 팝업을 연 시점의 카메라를 보관합니다. 좌·우회전 버튼은 현재 시점에서 초당 2°로 회전하며, 같은 방향을 다시 누르면 정지합니다. 시점 이동과 카메라 회전은 물리적인 공전·자전 배속과 별개입니다.

## 검증·제한

`npm test`는 저장소의 기존·신규 Node 검사를 실행합니다. `npm run test:v015`는 신규 단위·빌드 검사를 실행합니다. 신규 브라우저 검사: `python tests/v015_ui_browser.py`.

이번 패키지에서 수행한 단위·빌드 검사 26개와 격리된 브라우저 동작 검사 24개는 통과했습니다. 전체 앱의 기존 회귀 검사, Windows 실기기 검증, 실기기 FPS 측정은 미실시입니다. ESC 권한 제어 흐름은 모의 API로 검사했으며 실제 Chromium F 전체 화면 진입/종료는 별도로 확인했습니다.

자세한 설치·변경·검사 범위와 브라우저 제한은 `UPDATE_v0.15_KO.md`, 결과·파일 해시는 `docs/*v0.15*`에 있습니다. 이 전달은 변경 ZIP이며 GitHub 직접 푸시·웹 배포를 수행하지 않았습니다.
