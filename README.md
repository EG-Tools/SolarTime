# SOLAR TIME

**Life User · Solar Time v0.05 · Lyrikey@Naver.com**

실제 기기 시각과 같은 시간축에서 태양·8개 행성·지구의 달·명왕성이 움직이는 태양계 시계. 기본 JavaScript, CSS, Canvas 2D로 구현했으며 외부 라이브러리·이미지·CDN·계정 없이 실행됩니다.

## v0.05 복원

이 버전은 v0.04 위에 일부 모듈만 병합된 상태를 완성합니다. 버전 표시만 변경한 것이 아닙니다.

- `index.html`과 단일 HTML 빌드가 `surface.js`를 렌더러보다 먼저 불러옵니다.
- 화면에 보이는 천체의 표면만 공통 작업 스레드에서 계산합니다. 태양의 샤인만 보일 때 숨겨진 태양 표면까지 계산하지 않습니다.
- 확대용 표면은 2048×1024, 초점 천체의 래스터는 최대 1024×1024입니다. 실측 사진이 아닌 절차적 표면입니다. 작업 스레드가 불가능한 환경에서는 같은 커널의 저해상도 호환 경로를 사용합니다.
- 요청은 최신 상태로 합쳐지며, 동시에 실행하는 작업 묶음은 하나입니다. 기하 정보·시각 무효화·화면 밖 대상·수명주기가 바뀌면 오래된 결과는 폐기합니다. 탭을 숨기거나 페이지를 떠나면 작업자를 종료합니다.
- 하단 행성 버튼을 화면 중앙에 정렬하고 재생 카드를 더 내렸습니다. 제작자 표시를 Life User로 통일했습니다.
- 태양 주변 샤인은 v0.04보다 두 배 빠릅니다. 물리적 자전·공전 속도는 변경하지 않았습니다.

## v0.04 변경 (이전 버전)

- **상하 시점**: 좌클릭 드래그·방향키·설정 슬라이더 모두 -90°에서 +90°까지 조절하여 태양계 아래쪽도 볼 수 있습니다.
- **고리와 극점**: 토성·천왕성 고리는 행성 표면과 같은 자전축 좌표계를 사용하는 적도면에 배치합니다. 카메라 각도에 따라 기울기와 앞뒤 가림이 함께 변합니다. 고리 입자의 궤도 운동까지 계산하는 모형은 아닙니다.
- **확대 화질**: 가까이 볼 때 천체별 텍스처를 512×256에서 1024×512로 한 단계 올립니다. 확대 표면은 최대 768×768로 렌더링하며, 드래그 중에는 가벼운 미리보기를 사용하고 멈추면 상세도를 복원합니다. 저전력 렌더링은 최대 384×384입니다. 실측 사진이 아닌 기존 절차적 표면 표현을 유지합니다.
- **실시간 자전 검증**: 이전 버전 목성·토성 등은 1분 사이 실제로 회전했습니다. 속도는 변경하지 않았습니다. 느린 천체의 회전각 반올림 캐시가 미세한 화면 변화를 억제하던 문제를 모든 천체에 공통으로 수정했습니다. 물리적 자전·공전 주기는 그대로입니다.
- **일정한 최대 크기**: 모든 천체는 64배 추적 확대에서 화면 짧은 변의 68% 지름까지 커집니다. 달·명왕성도 태양과 같은 표시 크기가 됩니다. `가까이 보기`의 초기 화면 크기도 통일했습니다.
- **수직 이동**: 기본 태양계를 v0.03보다 화면 높이의 5% 위로 옮겼습니다. 마우스 가운데 버튼 드래그는 수직 이동만 하며, 기본 위치에서 화면 높이의 위·아래 20%까지 이동합니다. `0` / 기본 시점으로 각도·배율·이동을 복원합니다.
- **UI 정리**: 드래그·확대·추적 안내는 도움말의 단축키 설명 바로 위로 이동했습니다. 재생 카드는 확보된 공간만큼 아래로 내렸습니다. `1시간 / 초`는 추가하지 않았습니다.
- **태양 샤인**: 주변 코로나·홍염·가장자리 장식 변화만 3배 빠르게 했습니다. 태양 자전·표면의 물리적 회전·다른 천체·별 반짝임 속도는 유지합니다. 효과 끄기와 공전 일시정지는 기존처럼 작동합니다.
- 버전 오른쪽 이메일과 설정 하단 `Life User / Solar Time v0.04 / Lyrikey@Naver.com` 표시를 유지했습니다.

## v0.03 변경 (이전 버전)

- **태양 효과**: 구면 3D 노이즈로 입상 조직을 만들고, 다층 코로나·개별 수명주기를 가진 홍염·미세한 표면 흐름을 추가했습니다. 극점의 무늬 찌그러짐을 줄이고, 코로나 자산은 한 번만 생성해 재사용합니다.
- **달 궤도**: 지구 크기와 연결되어 44.85로 확대되던 표시 궤도 반지름을 독립된 30 기준 픽셀로 줄였습니다(약 33% 축소). 지구 크기는 v0.01의 1.5배를 유지하며, 달의 공전 주기와 행성의 실제 궤도 계산은 바꾸지 않았습니다.
- **확대·천체 추적**: 최대 3배에서 **64배**로 확대 범위를 늘렸습니다. 천체 더블클릭 또는 천체 정보의 **가까이 보기**로 해당 천체를 따라갑니다. 휠·+/−·두 손가락은 같은 확대 한계와 추적 상태를 사용합니다. **0 / 전체 보기**로 복귀합니다. 거리와 천체 크기의 화면 확대 축척은 서로 다릅니다.
- **구도**: 기본 전체 태양계의 궤도 경계 중심을 화면 높이의 **10% 아래**로 옮겼습니다.
- **이름 이동**: 태양·달·모든 행성에 같은 충돌 회피와 부드러운 이동을 적용했습니다. 짧은 겹침은 무시하고 위치 변경에는 유예 시간을 두어 반복적인 떨림을 줄였습니다. 궤도 이동은 즉시 따라가고, 이름의 상대 위치 조정만 보간합니다. 클릭 영역도 실제 표시 위치와 함께 움직입니다.
- **자전**: 실제 주기와 공전 배속의 연결을 유지합니다. `1일 / 초`에서 목성은 초당 약 2.42회, 토성은 약 2.27회 도는 것이 이 모델의 정상 동작입니다. 정보 패널에 현재 배속에서 보이는 자전 속도를 표시합니다. 요청에 따라 `1시간 / 초`는 추가하지 않았습니다.

## v0.02 변경 (이전 버전)


- 지구의 표시 반지름·지름을 v0.01의 **1.5배**로 확대했습니다. 다른 천체 크기와 행성 공전 궤도는 그대로입니다. 이 버전에서는 달의 표시 궤도도 함께 커졌으나, v0.03에서 분리했습니다.
- 자전은 각 천체의 **항성 자전 주기**와 공전에 사용하는 시뮬레이션 시각에서 계산합니다. 감상용 자전 가속이나 별도 자전 시계는 없습니다. 배속, 일시정지, 날짜 이동, 실제 시간 복귀도 같은 시각을 사용합니다.
- 금성·천왕성·명왕성의 역행 방향이 자전축 기울기와 중복 적용되지 않도록 수정했습니다. 표면 텍스처는 보간하여 느린 회전의 계단 현상을 줄였습니다.
- 감상 모드에서 **1.8초 동안 조작이 없으면 커서가 숨겨집니다.** 마우스 이동·키보드 조작 시 다시 나타납니다. 드래그 중에는 유지되며, 종료 후에는 정상 커서로 복귀합니다.

## 실행과 배포

루트의 `index.html` 또는 `dist/Solar-Time_v0.05.html`을 열면 로컬에서 실행됩니다. 이 복원 패키지의 GitHub 업로드는 보안 검사에서 차단되어, 생성 시점에는 공개 사이트에 반영되지 않았습니다. Pages는 `main` 브랜치의 루트를 게시합니다. 루트에 `index.html`, `styles.css`, `src/` 구조를 유지하세요.

오프라인 단일 HTML을 만들려면 Node.js 18 이상에서 실행합니다. `npm install`은 필요 없습니다.

```sh
npm test
npm run build
```

생성되는 `dist/Solar-Time_v0.05.html`을 Chrome 또는 Edge에서 열면 됩니다. `dist/`의 이전 버전 HTML은 보관본입니다. 소스를 고친 뒤에는 빌드를 다시 실행합니다.

## 시간과 조작

큰 디지털 시계는 항상 실제 기기 시각입니다. 외부 시간 서버에 접속하지 않으며 기기의 시계 설정을 따릅니다.

| 조작 | 태양계의 동작 |
| --- | --- |
| 실제 시간 | 기기 시각에 맞춰 실제 주기로 공전·자전 |
| 1일 / 초 | 1초에 시뮬레이션 1일 진행 |
| 7일 / 초 | 1초에 시뮬레이션 7일 진행 |
| 1년 / 초 | 1초에 시뮬레이션 365.25일 진행 |
| 일시정지 | 공전·자전·별·태양 효과 정지. 큰 시계는 계속 표시 |
| 날짜 선택 | 선택한 시각으로 이동 후 정지 |

지구의 자전은 약 **23시간 56분 4초**입니다. 실제 시간에서 움직임이 느리게 보이는 것이 정상입니다. 높은 배속에서는 프레임 간 여러 번 자전해 시각적 역회전이나 정지처럼 보이는 에일리어싱이 생길 수 있지만, 이를 숨기려고 자전 속도를 임의로 낮추지 않습니다.

실제 시간 모드의 일시정지 해제는 현재 시각으로 재동기화합니다. 배속 모드에서는 정지한 시각부터 이어집니다. 비활성 탭은 렌더링을 중단하지만 재생 중인 시뮬레이션 시각은 경과 시간을 반영합니다.

좌클릭 드래그로 시점 회전, 가운데 버튼 드래그로 수직 이동, 휠로 확대·축소하며 모바일에서 한 손가락 회전·두 손가락 확대를 지원합니다. 천체 또는 하단 이름을 누르면 공전 정보와 적용한 자전 주기를 확인할 수 있습니다.

**H** 감상 모드, **Esc** 패널 닫기·감상 모드 종료, **Space** 정지·재생, **R** 실제 시간, **F** 전체 화면, **0** 기본 45도 시점, **+ / −** 확대·축소.

설정은 브라우저에만 저장합니다. 저장 차단이나 손상된 설정은 실행을 막지 않습니다. 시스템의 동작 줄이기는 별·태양 장식 효과에 적용하며 물리적 자전 속도를 바꾸지 않습니다.

## 계산과 한계

관측 장비 조준·항법·월식이나 일식 예측용 정밀 천문력이 아닌 감상용 근사 모형입니다.

8개 행성 위치는 JPL의 장기 근사 궤도 요소 Table 2a/2b와 케플러 방정식을 사용합니다. 지구는 지구·달 질량중심으로 근사하며 UTC/TDB 차이는 생략합니다. 지원 날짜는 UTC 1800–2999년이며 끝에서 자동 정지합니다. 달은 평균 원 궤도, 명왕성은 고정 평균 타원 궤도입니다. 행성 중심과 궤도선은 같은 좌표식을 사용합니다.

자전 주기 단위는 지구 일이며 음수는 역행입니다. 대표 항성 주기를 사용합니다. 토성은 Cassini 고리 분석의 **10시간 33분 38초**, 천왕성은 Hubble 오로라 관측의 **17시간 14분 52초**를 채택했습니다. 가스 행성의 내부·구름층·위도별 회전과 태양의 차등 자전을 단일 주기로 완전히 표현할 수는 없습니다.

표면의 기준 경도는 J2000에서 임의로 정한 값입니다. 현재 시각에 실제로 보이는 대륙의 방향까지 맞춘 모형은 아닙니다. 자전축의 절대 방향, 고리 방향, 구름·태양 활동·배경은 시각적 표현입니다. 거리와 크기는 보기 좋게 조정했고 넓은 화면에서는 궤도 투영을 가로로 늘립니다. 명왕성은 왜행성, 소행성대는 생략합니다.

## 개발 파일

`src/astro.js`가 궤도·자전·시뮬레이션 시간의 계산을 소유합니다. `src/renderer.js`는 동일한 시각으로 장면을 그리고, `src/app.js`는 입력·커서 유휴 상태·UI·수명주기를 관리합니다. `styles.css`는 공통 UI와 감상 모드 커서를 담당합니다.

이름 재배치 애니메이션은 UI 동작입니다. 공전 일시정지 후에도 이름의 충돌 회피 전환은 마저 완료합니다. 감상 모드의 커서 자동 숨김은 v0.02와 같습니다.

수치·UI 배치 회귀: `npm test`. 오프라인 브라우저 회귀: `npm run build` 후 `python tests/browser_test.py` (Python Playwright와 Chromium 필요). 추가 뷰포트 회귀는 `python tests/view_browser_test.py`로 실행합니다. 검증 범위는 `docs/QA.md`를 참고하세요. 저장소의 배포 상태는 GitHub Pages의 Actions 기록을 기준으로 확인합니다. `docs/preview.png`는 v0.04 검증 중 촬영한 화면입니다.

복원 검증: `npm test`, `python tests/browser_test.py`, `python tests/recovery_browser_test.py`. `tests/view_browser_test.py`는 보관된 v0.04 단일 HTML에 대한 이전 회귀 검사입니다.
