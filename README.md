# SOLAR TIME

**Life User · v0.10 · Lyrikey@Naver.com**

실제 기기 시각으로 움직이는 감상용 태양계 시계입니다. 지구를 포함한 내장 재질은 인터넷 없이 즉시 표시하고, 연결 가능한 경우 나머지 천체의 공개 이미지 지도를 비동기로 받아 교체합니다. 위치 계산은 서버를 사용하지 않습니다.

## 실행

`dist/Solar-Time_v0.10.html`을 Edge 또는 Chrome에서 열면 됩니다. 개발용 진입점은 루트 `index.html`입니다. 별도의 npm 설치나 CDN JavaScript 의존성은 없습니다.

**이 패키지의 새 공개 사진은 사전 내장된 상태가 아닙니다.** 제작 환경에서 이미지 원본 파일 다운로드가 제한되어, 검증한 공개 원본 주소와 수신·적용·저장 기능을 연결했습니다. 새 사진을 처음 받으려면 사용자 브라우저의 인터넷 연결이 필요합니다. 기존 v0.06의 지구와 다른 천체의 내장 재질은 그대로 동봉되어, 사진을 받지 못해도 앱이 실행됩니다.

화면 설정의 `공개 이미지 n/8`이 수신 상태입니다. 처음 실행하면 자동으로 수신을 시도합니다. 일부 서버의 CORS 또는 연결 오류에는 고정된 공개 미러 주소로 제한적으로 재시도합니다. 모두 실패하면 기존 재질을 유지하고 `사진 다시 받기`로 다시 시도할 수 있습니다.

성공한 사진은 브라우저의 IndexedDB에 저장을 시도합니다. 브라우저 저장소 차단 또는 삭제에 대비해 **`이미지 포함 HTML 저장`** 버튼을 제공합니다. 이 버튼으로 저장한 HTML에는 *그 시점까지 수신한 이미지*가 실제 데이터로 포함됩니다. `8/8`에서 저장한 파일은 다른 기기에서도 인터넷 없이 8개 공개 이미지를 보여줍니다. `0/8`에서 저장하면 기존 내장 이미지가 포함되며, 수신하지 못한 이미지가 들어갔다고 표시하지 않습니다.

## v0.10 변경

- 감상 모드에서도 시계 아래의 `SEOUL` 등 시간대 표기를 **정적인 글자**로 유지합니다. 일반 모드에서는 기존 시간대 전환 버튼을 그대로 사용합니다. 한국 위치 표식과 실제 시각은 변경하지 않았습니다.
- 사용 방법 버튼 아래에 카메라 저장 번호 `1 / 2 / 3`을 추가했습니다. **마우스 왼쪽 클릭은 현재 시점 저장/덮어쓰기**, **키보드 1·2·3은 저장된 시점 불러오기**입니다. 각도, 확대율, 상하좌우 이동, 추적 대상을 함께 보관하고 날짜·재생속도는 바꾸지 않습니다.
- 저장된 번호를 우클릭하면 커서 근처에 삭제 확인창이 열립니다. 화면 가장자리에서는 창이 잘리지 않도록 위치를 보정합니다. 삭제 버튼을 다시 눌러야 지워지고, 취소·Esc·바깥 클릭은 그대로 둡니다. 처음 포커스는 취소 버튼입니다.
- 번호 버튼은 감상 모드에서 숨겨지지만, 숫자 단축키는 그대로 작동합니다. 기존 기본 시점·모드 전환 버튼은 활동 중에만 표시하는 동작을 유지합니다.
- 저장은 브라우저의 localStorage를 사용합니다. 같은 브라우저 저장소에서 다시 열면 복원하며, 저장이 차단된 환경에서도 현재 창 안에서는 동작합니다. 다른 사이트/프로필 또는 일부 파일 주소에서는 브라우저의 저장소 분리 정책이 적용됩니다. 이미지 포함 HTML에 사용자 시점 저장값을 자동으로 넣지는 않습니다.
- 천체 이미지 교체 시 기존 정상 비트맵을 먼저 없애지 않습니다. 완료된 교체 이미지의 대상·작업 세대·크기 등을 검사한 다음 바꾸도록 했습니다. 오래된 작업의 오류도 현재 렌더링을 재설정하지 못하게 했고, GPU 문맥 손실은 정상 이미지로 반영하지 않습니다. 모든 천체가 같은 처리를 사용합니다.
- **목성의 보라색 순간 변색 자체는 이번 환경에서 재현하지 못했습니다.** 확인된 이미지 교체 공백과 비동기 응답 취약점을 수정한 것으로, 사용자 GPU에서 해당 현상이 완전히 해결됐다는 검증은 아닙니다.

### 변경 파일 ZIP 적용

기존 **v0.09 전체 프로젝트의 `SolarTime` 폴더**에 이번 변경 ZIP의 `SolarTime` 내용물을 같은 경로로 덮어씁니다. 변경하지 않은 `assets/`와 `src/assets.js`는 기존 것을 유지합니다. 새 오프라인 실행본은 `dist/Solar-Time_v0.10.html`입니다. 이전 실행본을 열면 이전 버전이 표시됩니다.

단일 HTML만 사용하는 경우에는 새 v0.10 HTML을 직접 열면 되고 소스 패치를 적용할 필요가 없습니다. 코드 수정 후에는 `npm run build`로 단일 HTML을 다시 생성합니다.

## v0.08 변경

- GPU를 사용할 수 없는 CPU 호환 경로에서도 가로 경계를 감싸는 선형 보간을 사용합니다. 하드웨어 경로와 같은 텍셀 중심 및 밝기 계산을 사용합니다.
- 브라우저 탭 제목은 정확히 **Solar Time**입니다. 설정과 하단 버전은 v0.08입니다.
- 달·명왕성처럼 작은 천체의 추적 확대값이 다른 모든 천체에 적용되던 문제를 수정했습니다. 공통 줌과 추적 대상의 표시 반지름을 분리해 태양까지 거대해지는 현상을 방지합니다. 모든 천체의 최대 추적 크기는 종전처럼 짧은 화면 변의 68%입니다.
- 드래그 직후 발생하는 더블클릭 신호를 걸러, 의도하지 않은 추적 전환을 방지합니다. 정상적인 두 번 클릭·정보 패널 추적·휠 확대는 유지합니다.
- 지구와 달의 근접 표시 간격만 두 표시 반지름에서 계산하고, 위치와 궤도선이 같은 값을 공유합니다. 실제 공전·자전 수치, 행성 재질 수신·보관, 배속, 감상 모드, 혜성, 태양 샤인 속도는 그대로입니다.

배경만 다시 굽기: `python tools/bake_sky.py` (개발용 numpy/scipy/Pillow 필요). 실행 시에는 새 계산·다운로드를 하지 않고 내장 이미지만 사용합니다.

- 지구의 NASA Blue Marble 내장 이미지는 변경하지 않았습니다. 명왕성·태양·배경은 기존 예술적 재질입니다.
- 새 이미지와 일치하지 않는 예전 가상 요철 지도는 해당 천체에서 제거합니다. 실제 이미지 위에 잘못된 크레이터나 줄무늬를 덧씌우지 않습니다.
- **셰이더 출력은 최대 1024×1024**입니다. 원본 이미지의 디테일은 따로 유지하여, 8K 원본은 최대 4096×2048로 줄이고 2K 원본은 2048×1024 그대로 사용합니다. CPU 호환 렌더링은 최대 768입니다. 텍스처 해상도와 최종 셰이더 출력 크기는 별개입니다.
- 우주 배경의 저주파 안개 성분을 약 62% 줄였습니다. 별빛의 작은 밝은 점과 기존 360도 연결 구조를 유지합니다.
- 혜성은 구면 좌표에서 3차 곡선으로 이동합니다. 꼬리도 지나간 곡선을 따르며, 한 번에 약 11–18초 동안 멀리서 지나갑니다. 궤도 예측이 아닌 장식 효과입니다.
- **v0.07에서는 감상 모드의 모든 버튼·링크를 숨겼습니다. v0.09부터는 활동 중에만 두 조작 버튼이 나타납니다.** `H` 또는 `Esc`, 모바일 세 손가락 터치로 종료합니다. 숨겨진 UI를 키보드로 잘못 조작하지 않도록 비활성화합니다.
- **태양 샤인 변화만 v0.06의 4배**입니다. 태양의 자전, 행성 공전, 별 반짝임, 구면 배경 속도는 가속하지 않습니다. 제거했던 홍염과 테두리 물결은 되살리지 않았습니다.

## 조작

좌클릭 드래그는 시점 회전, 휠은 확대·축소, 가운데 버튼 드래그는 상하좌우 각각 ±20% 이동입니다. `0`은 기본 시점입니다. 천체 더블클릭 또는 정보 패널의 가까이 보기로 추적합니다. 모든 천체는 최대 추적 확대에서 같은 화면 크기로 표시됩니다.

`H` 감상 모드, `Esc` 감상 모드 종료/패널 닫기, `F` 전체 화면, `Space` 정지/재생, `R` 실제 시간 복귀. 기본 배속은 실제 시간·1일/초·7일/초·1년/초입니다. 1시간/초는 추가하지 않았습니다.

## 시간 모델

v0.06의 `src/astro.js`를 그대로 유지했습니다. 자전·공전 주기는 초 단위 소수점 둘째 자리, 축 기울기는 도 단위 소수점 둘째 자리이며, 표시 회전각은 반올림하지 않습니다. 실행 시 기기 시각으로 기준을 보정하고 경과 시간에서 위치를 계산합니다. 인터넷 연결 여부는 천체 위치·자전·시계에 영향을 주지 않습니다.

크기와 거리를 감상용으로 조정한 외부 시점입니다. 화면에서 달과 태양이 겹쳐도 실제 지구의 일식을 의미하지 않습니다. 지구의 낮/밤은 근사 표시이며 목성의 붉은점 등 무늬의 현재 실제 경도는 예측하지 않습니다.

## 개발과 검증

Node.js 18 이상. 패키지 설치 없이 실행할 수 있습니다.

```sh
npm test
npm run build
```

빌드는 로컬 `assets/`를 `src/assets.js`에 포함하고 단일 HTML을 만듭니다. 빌드 과정에서는 인터넷 이미지 다운로드를 수행하지 않습니다.

Python Playwright와 Chromium이 있는 환경의 검사:

```sh
python tests/release_browser.py
python tests/materials_browser.py
python tests/sky_bake_test.py
```

첫 검사는 완전 오프라인 실행을, 두 번째는 **가상 이미지 응답**으로 수신 성공·실패·취소·출처·오프라인 재저장을 검증합니다. 두 번째가 실제 공개 서버에서 다운로드했다는 뜻은 아닙니다. 실기기 GPU, 실제 서버의 CORS 응답, Windows 파일 더블클릭과 브라우저 저장소의 지속성은 이 환경에서 검증하지 못했습니다.

검사 보고서: `docs/QA.md`, `docs/viewing-controls-v0.10.json`, `docs/camera-presets-v0.10.json`. 이전 버전의 보고서는 파일명에 해당 버전이 명시되어 있습니다.

카메라 저장 집중 검사: `python tests/camera_presets_browser.py` (저장소는 테스트용 메모리 어댑터).

감상 모드 집중 검사: `python tests/viewing_controls_browser.py` (오프라인 HTML 주입 및 포인터·키보드·터치 조작).
