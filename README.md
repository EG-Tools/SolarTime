# Solar Time

**Life User • Solar Time v0.34 • Lyrikey@Naver.com**

실제 기기 시각으로 움직이는 감상용 태양계 시계입니다. 관측·항법용 정밀 천문력이 아닙니다.

## v0.34 변경

- Chrome과 Edge의 투명 GPU 캔버스 합성 방식을 통일해 궤도선이 브라우저에 따라 사라지거나 지나치게 어두워지던 문제를 해결했습니다.
- F11 전체 화면 전환과 복귀 시 새 화면 크기의 GPU·캔버스 프레임을 완성한 뒤 표시해 궤도선과 행성 고리가 순간적으로 튀는 현상을 줄였습니다.
- 궤도선의 시작 표시와 팝업·메뉴·감상 모드 조작 패널을 부드러운 페이드로 통일하고 카메라 배율 표시가 늦게 따라오던 현상을 수정했습니다.
- 우클릭 메뉴와 텍스트 드래그 선택을 차단해 감상 중 의도치 않은 브라우저 동작을 방지했습니다.
- 공개 화면은 작은 버전표를 캐시 없이 확인해 새 릴리스를 자동으로 불러옵니다. 10MB 이상의 천체 재질 묶음은 실제 재질이 바뀔 때만 새 주소를 사용해 버전마다 중복 다운로드하지 않습니다.
- v0.34와 충돌하던 과거 카메라·렌더링·브라우저 자동화 테스트를 제거하고, 현재도 유효한 기능 검증과 v0.34 릴리스 검증만 유지합니다.

## v0.33 변경

- 사용자가 확정한 카메라 구도, 화면 옵션, 천체 크기와 위성 궤도 값을 새 초기 설정으로 적용하고 초기화 확인 절차를 추가했습니다. 카메라 1·2·3 저장값은 초기화 후에도 유지됩니다.
- 천체 카드에서 표시 크기와 태양·지구·목성 하위 궤도 간격을 조절할 수 있으며 실제 크기 모드에서는 이 시각화 옵션을 잠급니다.
- 토성과 천왕성 고리에 거리·투영 두께 기반 세부 단계 보정을 적용해 멀리서 생기는 모아레와 자글거림을 줄였습니다.
- 초기화 팝업과 예·아니오 버튼을 화면 및 카드 중앙에 맞추고, 우주 배경 방향은 새로 열 때마다 달라지도록 했습니다.

## v0.32 변경

- 실제 크기와 일반 보기의 행성·위성 크기 및 궤도 계층을 분리해 달·유로파와 태양계 궤도가 올바른 부모 크기를 따르도록 정리했습니다.
- 행성 카드에 천체별 표시 크기 조절을, 설정에 일반 보기 궤도 간격과 24시간 표기 토글을 추가했습니다.
- 줌과 실제 카메라 이동을 분리하고, 천체 중심 이동·부드러운 기본 시점·카메라 1·2·3 모드 저장을 적용했습니다.
- 좌·우 자동 회전은 카메라 조작·시점 이동·페이지 재실행에도 유지되며 사용자가 활성 버튼을 다시 눌렀을 때만 꺼집니다.
- 전체 화면 전환 시 새 화면 크기로 궤도를 즉시 다시 계산해 늦게 나타나던 현상을 수정했습니다.
- 배경을 가벼운 2K 레이어와 GPU 별 필드로 최적화하고 태양·천왕성·명왕성·유로파 재질 및 다국어 UI를 보강했습니다.

## v0.31 변경

- 우측 카메라 조작 패널에 `줌/이동` 전환을 추가했습니다. 기본은 기존 줌이며, 이동 모드에서는 카메라가 실제로 전진·후진해 가까운 천체와 먼 천체의 원근감이 드러납니다.
- 좌클릭 세로 회전을 전 방향으로 열고 가운데 버튼 이동 범위를 화면 기준 ±80%로 넓혔습니다.
- 카메라 시점 1·2·3에 줌/이동 방식까지 함께 저장하고, 모드가 다른 시점을 불러올 때도 부드럽게 전환합니다.
- 좌측 하단 정보는 축척·출처, 버전·연락처, 저작권 순서의 3줄로 정리했습니다.

## v0.3 변경

- 태양 표면의 밝고 어두운 플라스마 결, 미세 왜곡, 코로나 광선의 변화 주기를 개선했습니다.
- 태양·명왕성·천왕성·유로파의 구면용 텍스처를 보강하고 천왕성의 여러 가는 고리를 새로 구성했습니다.
- 실제 크기 비율 모드를 추가했으며 켜고 끌 때 2초 동안 부드럽게 전환됩니다. 별 반짝임은 항상 활성화됩니다.
- 한국·미국·중국·일본·영국의 지역 시각과 지구 표면 위치를 연결하고 한국어·영어·중국어·일본어 UI를 지원합니다.
- 시계 중앙 정렬, AM/PM 배치, 투명 카드 디자인, 행성 카드의 아래 방향 확장과 일본어 줄바꿈을 다듬었습니다.

## v0.25 변경

- GPU 행성보다 위에 그려지던 별 반짝임과 혜성을 행성 원판에서 가려 모든 행성 표면이 불투명하게 보이도록 수정했습니다.
- 숫자 시간은 화면 중앙을 유지하고 AM/PM 표시는 오른쪽 아래에서 10px 위로 독립 배치했습니다.
- 명왕성은 New Horizons 전구 컬러 지도를 시각 기준으로 삼아 AI가 완전한 구면용 텍스처로 재구성했습니다. 관측이 부족한 남반구는 예술적 생성 영역이며 과학 자료가 아닙니다. 천왕성은 Voyager 2 사진 기반 재질입니다.
- 태양은 NASA/GSFC SDO/AIA 171 Å 전면 사진을 시각 기준으로 AI가 늘어짐 없는 완전한 구면 재질로 재구성했으며, 코로나 이펙트는 기존처럼 별도 렌더링합니다.
- 시계 숫자 획 자체는 중앙정렬을 유지한 반투명 유리 재질이며 별도의 카드 테두리는 없습니다. 하단 시간 설정 카드는 외곽선만 남기고 내부를 완전 투명하게, 감상 모드 버튼 배경도 투명하게 표시합니다.
- 화면 설정과 도움말은 약 10% 투명도와 약한 블러의 유리 카드로 통일하고 화면 전체를 어둡게 하는 모달 배경막을 제거했습니다. 도움말 스크롤 막대는 숨기고 휠·터치 스크롤, 고정된 닫기 버튼, 위·아래 내용 화살표를 사용합니다.
- `태양 → 지구 → 달`, `태양 → 목성 → 유로파` 부모-자식 구조를 추가했습니다. 달과 유로파는 JPL 기준 시각의 위치에서 시작해 현재 시뮬레이션 시각을 따라 약한 타원 궤도로 움직입니다.
- 위성 이심률은 달 0.05, 유로파 0.01만 사용하며 장기 섭동과 연간 미세 거리 변화는 계산하지 않습니다.
- 기존 GPU 표면 렌더링, 카메라 조작, 축 기울기, 태양 샤인 효과는 그대로 유지합니다.
- 배포용 `dist`는 최신 단일 HTML만 유지합니다.

## 조작

좌클릭 드래그: 전 방향 시점 회전. 가운데 버튼 드래그: 상하좌우 ±80%. 우측 `줌/이동`: 휠·+/− 작동 방식 전환. 천체 더블클릭·가까이 보기: 추적. 0: 기본 시점. 1·2·3: 방식까지 포함한 저장 시점. H: 감상 모드. F: 전체 화면. ESC: 감상 → 전체 화면 → 팝업/패널 순서. Space: 정지/재생. R: 실제 시간.

## 배속

시간: 1분~24시간 / 초, 일: 1~365일 / 초, 년: 1~20년 / 초. 단위 버튼은 시간 → 일 → 년 순서로 순환합니다.
