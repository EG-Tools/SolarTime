# Solar Time

**Life User · v0.13 · Lyrikey@Naver.com**

실제 기기 시각으로 움직이는 감상용 태양계 시계입니다. 탭 제목은 `Solar Time`입니다. 위치·자전은 로컬 계산이며 내장 재질과 배경은 인터넷 없이 동작합니다. 관측·항법용 정밀 천문력이 아닙니다.

## v0.13 변경

- **카메라 팝업 통합:** 1·2·3을 좌클릭하거나 우클릭하면 동일한 `적용 / 저장 / 삭제 / 취소` 팝업이 마우스 위치에 열립니다. 빈 번호에서는 적용·삭제가 비활성화됩니다. 적용과 키보드 1·2·3은 기존의 부드러운 시점 전환을 사용합니다. 저장은 팝업을 열었을 때의 각도·확대·이동·추적 대상을 저장/덮어쓰며 삭제는 해당 번호만 지웁니다. 취소·Esc·창 밖 클릭은 변경하지 않습니다.
- **감상 모드 토글 통합:** 하단의 감상 모드 글자 버튼을 제거했습니다. 오른쪽 우회전 바로 아래에 동일한 크기의 눈 모양 아이콘이 항상 있습니다. 같은 버튼으로 감상 모드를 켜고 끕니다. 감상 중 마우스 이동·클릭·터치로 오른쪽 조작부가 나타나고 1.8초 유휴 후 커서와 함께 숨습니다. 서울/시간대 글자는 남습니다.
- **텍스처 이음선:** 내장·온라인 수신 이미지 모두 디코딩 직후 같은 경계 보정 경로를 사용합니다. 원본 경도의 양쪽 1.5%(최대 각 64픽셀)만 부드럽게 연결하며 한국 등 내부 경도 좌표를 이동시키지 않습니다. 색상·구름·요철 지도에 동일하게 적용합니다. GPU의 경도 불연속에서 과도한 mip 선택이 발생하지 않도록 기본 레벨 선형 샘플링을 사용하고, CPU도 같은 텍셀 중심에서 좌우를 감싸며 보간합니다.
- **더 큰 클로즈업:** 더블클릭/가까이 보기는 화면 짧은 변의 50% 지름으로 시작합니다(기존 28%). 추가 확대 상한은 64에서 256으로 늘렸습니다. 기존 64배 이하 시점의 크기는 보존하고, 64배를 넘는 추가 크기는 추적 대상에만 적용합니다. 최대 지름은 화면 짧은 변의 220%이며 화면 밖으로 잘릴 수 있습니다. 지구 선택 → `한국 보기` → 휠 확대 순서로 한국을 관찰합니다.
- **탭 복귀와 조작 화질:** 탭을 숨길 때 완성된 이미지와 디코딩된 재질 캐시를 유지합니다. 새 작업은 멈추고 진행 중인 한 묶음의 낡은 결과는 폐기합니다. 돌아오면 유지한 이미지를 즉시 사용하며 최신 시점 결과가 준비될 때 교체합니다. 카메라 드래그 때 저해상도로 내려갔다 올라가는 처리를 제거했습니다. 처음 재질을 준비하는 동안 가짜 단색 행성 원판을 그리지 않습니다. 같은 재질·화질의 완료된 프레임만 제한된 시점 차이(수동 최대 5°, 자동 최대 1.5°)에서 사용할 수 있고 조작 종료 시 정확한 최종 각도로 갱신합니다.
- **이름 기본 고정:** 천체 이름은 각 천체 아래에 고정됩니다. 설정의 `이름 겹침 자동 정리`를 켜야 예전처럼 충돌을 피하며 부드럽게 움직입니다. 초기값은 OFF입니다.
- **초 숫자 기본 숨김:** `시계 초 표시`의 초기값은 OFF입니다. ON일 때만 초 구분자와 숫자를 함께 표시합니다. 표시 옵션은 자전·공전·시뮬레이션 시간에 영향을 주지 않습니다.

재질 원본 해상도와 셰이더 출력은 별개입니다. 집중한 천체의 텍스처는 최대 4096×2048, GPU 출력은 최대 1024×1024입니다. GPU를 사용할 수 없는 CPU 호환 출력은 최대 768×768입니다. 이번 버전은 새로운 사진을 추가하지 않았으며 기존 이미지, 우주 배경·혜성·샤인 속도 및 천체 시간 모델은 유지했습니다.

## 실행과 업데이트

`dist/Solar-Time_v0.13.html`을 Chrome/Edge에서 엽니다. 개발용 진입점은 루트 `index.html`이며 Node.js 18 이상에서 `npm run build`로 단일 HTML을 만듭니다. `npm install`은 필요 없습니다.

변경 ZIP은 **기존 v0.12 프로젝트의 SolarTime 폴더**에 같은 경로로 덮어씁니다. 이미지와 `src/assets.js`는 동일하므로 다시 넣지 않았습니다. 이전 버전에서 건너뛰어 적용하지 마세요. 단일 HTML만 사용하는 경우 새 v0.13 HTML을 엽니다. 저장한 시점의 키·스키마는 유지했으며 새 버전이 기존 시점을 지우지 않습니다. 저장소 접근 권한은 브라우저/파일 실행 환경에 따릅니다.

공개 이미지 수신은 선택적인 기존 기능입니다. 내장 재질로 먼저 실행하고, 온라인이면 지정된 공개 지도 다운로드를 비동기로 시도합니다. 사진을 받지 못하면 내장 재질을 사용합니다. `설정 → 공개 이미지 n/8`에서 확인하고 `이미지 포함 HTML 저장`으로 실제 수신한 사진을 새 실행 파일에 포함할 수 있습니다. 사진 캐시도 이음선 보정 후 렌더링됩니다.

## 조작

오른쪽 도구 순서: **+ / − / 배율 / 기본 시점 / 1 / 2 / 3 / 좌회전 / 우회전 / 감상 모드**.

좌클릭 드래그로 −90°~+90° 관찰, 가운데 버튼 드래그로 상하좌우 각각 ±20% 이동, 휠로 확대/축소합니다. `0`은 기본 시점, `H`는 감상 모드, `Esc`는 팝업 취소·감상 모드 종료, `F`는 전체 화면, `Space`는 시뮬레이션 정지/재생, `R`은 실제 시간 복귀입니다. 1·2·3 단축키는 저장 시점을 적용합니다.

좌·우회전은 현재 시점에서 초당 2°로 회전합니다. 같은 방향을 누르면 정지하고 반대 방향을 누르면 전환합니다. 드래그·휠·시점 적용·기본 시점은 자동 회전을 멈춥니다. 감상 모드 토글은 카메라 회전을 유지합니다. 시뮬레이션 배속/일시정지와 카메라 회전은 별개입니다.

## 검증

`npm test`는 계산·좌표계·표면 수명주기·시점·라벨·재질 회귀를 실행합니다. 집중 브라우저 검사는 Python Playwright/Chromium이 있는 환경에서 `python tests/refinements_browser.py`를 사용합니다. `SECTION=ui`, `SECTION=graphics`, `SECTION=mobile`로 나눠 실행할 수 있습니다. `MODE=bundle`은 빌드된 단일 HTML을 사용합니다. 모바일은 `WIDTH=320`, `390`, `844`로 범위를 좁힐 수 있습니다.

검증 상세 및 제한은 `docs/QA.md`, `docs/release-verification-v0.13.json`을 참고하세요. 이번 전달은 HTML과 변경 ZIP이며 GitHub 푸시·병합·웹 배포를 수행하지 않았습니다.
