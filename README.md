# Solar Time

**잠시 우주를 바라보는 시간**

현재 시각과 태양계의 움직임을 음악과 함께 감상하는 웹 앱입니다. 데스크톱 PC 환경에 최적화되어 있습니다.

**실행:** https://solartime.app/

## 주요 기능

행성·위성 가까이 보기, 지역별 시계, 시간 이동, 일식·행성 정렬 탐색, 배경음악, 감상 모드, 알람과 Windows 예약 종료를 제공합니다.

## 기본 조작

왼쪽 드래그는 회전, 가운데 드래그는 화면 이동, 휠은 전진·후진, 오른쪽 드래그는 줌인·아웃입니다. 천체를 더블클릭하면 가까이에서 추적합니다.

`0` 기본 시점 · `1–3` 저장 시점 · `← →` 천체 선택 · `↑ ↓` 전진·후진 · `Space` 일시정지 · `R` 실제 시간 · `F` 전체 화면 · `H` 감상 모드

## 이용 안내

Windows 예약 종료에는 별도의 보조 모듈이 필요합니다. 종료 전에는 작업을 저장하세요.

교육·감상용 시뮬레이션이며, 정밀 관측·항법·일식 예측용이 아닙니다. 천체 크기와 거리는 보기 쉽게 조정될 수 있습니다.
