# Solar Time

**Life User · v0.16 · Lyrikey@Naver.com**

실제 기기 시각으로 움직이는 감상용 태양계 시계입니다. 탭 제목은 Solar Time입니다. 위치·자전은 로컬 계산이며 내장 이미지와 배경은 오프라인으로 동작합니다. 관측·항법용 정밀 천문력이 아닙니다.

## v0.16

모든 카메라 전환은 중간 전체 구도나 별도 줌 브리지를 거치지 않고 현재 상태에서 목적 상태까지 직접 이동합니다. 방위각은 최단 회전 방향을 사용하고, 시작과 끝에서만 동일한 5차 스플라인 이징으로 부드럽게 가감속합니다.

카메라의 전체 태양계 맞춤 배율을 관찰 각도와 분리했습니다. 그래서 좌클릭으로 위·아래 시점을 돌리거나 좌·우 자동 회전을 할 때 카메라 각도 때문에 화면이 확대됐다 축소되는 느낌이 나지 않습니다. 자동 회전은 현재 팬 위치와 확대를 그대로 유지하고 현재 화면 중심을 기준으로 시작합니다.

가운데 버튼으로 옮긴 뒤 천체 추적을 시작하면 최종적으로 천체가 화면 중앙에 오도록 팬 오프셋을 함께 보간합니다. 휠 확대는 숨은 추적 대상을 만들지 않습니다. `한국 보기`는 지구를 약 1800×까지 확대하고 서울 위치를 표시하며, 최대 수동 확대는 2048×입니다.

기존 1일/7일/1년 버튼 대신 가로 슬라이더를 사용합니다. 단위는 **시간 / 일 / 년** 토글입니다. 시간은 1분~48시간을 1분 단위, 일은 1~365일을 1일 단위, 년은 1~10년을 1년 단위로 1초당 진행량을 설정합니다. 예: `30분 / 초`, `1시간 34분 / 초`.

현재 우주 배경은 사용자가 제공한 **4096×2048 원본 WebP**를 그대로 유지하며, v0.16에서는 배경 이미지를 수정하지 않습니다.

## 실행·업데이트

GitHub Pages는 루트 `index.html`을 사용합니다. v0.16 변경 ZIP의 **내용물을 기존 SolarTime 프로젝트 루트에 덮어쓰고 GitHub에 올리면** 적용됩니다. 이번 배포는 기존 `src/assets.js` 다음에 배경 전용 `src/sky-asset.js`를 읽으므로 **웹 버전 업데이트에 별도 빌드는 필요 없습니다.**

단일 파일 실행은 Node.js 18 이상에서 `npm run build` 후 `dist/Solar-Time_v0.16.html`을 열면 됩니다. npm install은 필요 없습니다. 빌드는 기존 행성 자료를 포함하고 배경은 한 번만 넣습니다. 기존 dist의 과거 버전은 유지합니다.

배경을 나중에 직접 교체할 때는 `node tools/pack_assets.cjs` 또는 `npm run build`로 이미지와 JavaScript 묶음을 함께 갱신하세요. ‘이미지 포함 HTML 저장’은 실제 수신한 공개 사진과 현재 배경을 함께 저장합니다.

## 조작

좌클릭 드래그: 회전. 가운데 버튼 드래그: 상하좌우 ±20% 이동. 휠·+/−·핀치: 확대/축소. 천체 더블클릭·가까이 보기: 부드러운 추적. 0: 기본 시점. 1·2·3: 저장한 시점. H: 감상 모드. F: 전체 화면. ESC: 감상 → 전체 화면 → 패널 해제. Space: 시뮬레이션 정지/재생. R: 실제 시간 복귀.

오른쪽 숫자 버튼은 좌·우클릭 모두 적용/저장/삭제/취소 팝업을 엽니다. 저장은 팝업을 연 시점의 카메라를 보관합니다. 좌·우회전 버튼은 현재 시점에서 초당 2°로 회전하며, 같은 방향을 다시 누르면 정지합니다. 시점 이동과 카메라 회전은 물리적인 공전·자전 배속과 별개입니다.

## 검증·제한

`npm test`는 저장소의 기존·신규 Node 검사를 실행합니다. `npm run test:v016`은 v0.16 카메라 회귀 검사를 실행합니다. 기존 v0.15 검사도 `npm test`에 함께 포함됩니다.

v0.16은 카메라 중심·추적 전환·현재 중심 자동회전·한국 보기 확대를 회귀 검사합니다. 전체 앱의 Windows 실기기 FPS 측정은 별도입니다.

자세한 설치·변경·검사 범위와 브라우저 제한은 `UPDATE_v0.16_KO.md`에 있습니다. 이 전달은 변경 ZIP이며 GitHub 직접 푸시·웹 배포를 수행하지 않았습니다.
