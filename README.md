# Solar Time v0.06

Life User / Solar Time v0.06 / Lyrikey@Naver.com

태양계 시계와 360도 우주 감상 화면. 시뮬레이션은 **기기 시각과 로컬 계산식**만 사용합니다.

## 실행

`dist/Solar-Time_v0.06.html`을 Chrome/Edge에서 엽니다. 설치·로그인·API 키·인터넷 연결이 필요하지 않습니다. 파일에 이미지, 코드, 스타일을 포함했습니다. 다운로드하지 않은 웹사이트를 인터넷 없이 처음 방문할 수 있다는 뜻은 아닙니다. 오프라인 사용에는 HTML을 미리 저장해야 합니다.

개발용 원본은 루트의 `index.html`, `styles.css`, `src/`, `assets/`입니다. GitHub Pages로 공개할 때는 이 구조 그대로 게시합니다. 이 패키지는 저장소 푸시나 공개 배포가 완료되었다는 증명이 아닙니다.

## v0.06

- 초기 구도와 확대 구도 모두 태양을 수평 중앙에 둡니다. 명왕성의 비대칭 궤도 경계가 중심을 바꾸지 않습니다.
- 감상 모드에도 기존 기본 시점 버튼을 유지합니다. H/Esc로 감상 모드를 종료하고 0으로 위치·시점을 초기화합니다.
- 좌클릭 드래그로 −90°부터 +90°까지 회전하고, 가운데 버튼 드래그로 가로·세로 각각 화면의 ±20% 이동합니다.
- 최대 확대 64×에서 달·명왕성도 다른 천체와 같은 화면 비율로 커집니다. 각 천체를 더블클릭하거나 가까이 보기를 누르면 따라갑니다.
- 지구는 NASA Blue Marble 기반 영상, 나머지 천체는 4096×2048의 구면용 예술적 재질을 사용합니다. 목성의 붉은 소용돌이 위치는 실제 관측 경도가 아닙니다.
- GPU가 지원되는 환경에서는 구면 셰이더·표면 요철·조명을 사용합니다. GPU가 없으면 같은 좌표식을 쓰는 제한된 해상도의 CPU 경로로 전환합니다. Worker가 지원되면 표면 계산을 별도 스레드에 둡니다.
- 별과 은하 배경은 경도가 이어지는 360도 구면입니다. 카메라 회전에 따라 보이는 방향이 바뀌고, 장식용으로 천천히 회전합니다. 우주 배경의 이동은 실제 은하 운동이 아닙니다.
- 혜성은 간헐적으로 멀리 지나가는 장식 효과입니다. 실제 혜성 목록을 조회하지 않습니다. 설정에서 혜성과 배경 회전을 각각 끌 수 있습니다.
- 태양은 샤인만 남겼습니다. 테두리 물결·홍염·표면 일렁임은 제거했고 실제 자전은 유지합니다.
- 한국 보기에서 서울 위치를 표시하고 간단한 근사 계산으로 낮·밤을 안내합니다. 지구를 향한 카메라만 바꾸며 시간이나 지구 회전을 임의로 바꾸지 않습니다.

## 시간과 오프라인 보정

앱을 실행할 때 기기 시각으로 모든 기준 위치를 **로컬에서 보정**합니다. 이후에는 고정된 축과 자전·공전 주기에서 경과 시간으로 위상을 계산합니다. 주기는 **초 단위 소수점 두 자리**, 축 기울기는 도 단위 소수점 두 자리입니다. 매초 회전각을 소수점 두 자리로 반올림하지는 않습니다. 그렇게 하면 느린 천체는 각속도가 0이 되기 때문입니다.

실행을 계속하는 경우 UTC 새해에 기준을 갱신합니다. 날짜 선택과 현재 시간 복귀 때에도 로컬 기준을 다시 맞춥니다. 프레임 수를 누적해 시간이나 위상을 계산하지 않으므로 렌더링 누락이 공전 주기를 바꾸지 않습니다.

온라인/오프라인 여부를 확인하거나 서버 응답을 기다리는 코드가 없습니다. 기기 시계가 틀리면 화면의 시각과 위치도 그에 영향을 받습니다. 연간 오차가 모든 천체에서 몇 초 이내라고 보장하는 정밀 천문력은 아닙니다.

큰 시계는 실제 기기 시각입니다. 태양계만 실제 시간 / 1일·7일·1년당 1초 중 선택한 배율로 움직입니다. 1시간/초는 추가하지 않았습니다.

## 표현의 한계

지구·달 질량중심을 지구 위치로 사용하고, 달은 기울어진 평균 원 궤도, 명왕성은 평균 타원으로 단순화했습니다. 표면, 구름, 자전축의 절대 방향과 고리 재질은 감상용 표현입니다. 크기와 거리가 실제 축척이 아니므로 **화면에서 달이 태양을 가려도 실제 일식이라는 뜻은 아닙니다.** 일식 예측이나 항법용으로 사용하지 않습니다.

## 개발과 검증

Node.js 18 이상에서 추가 npm 패키지 없이:

```sh
npm test
npm run build
```

빌드는 `assets/`를 `src/assets.js`에 묶고 소스를 단일 HTML에 넣습니다. 포함된 원본 이미지를 재생성하는 경우에만 Python의 NumPy·SciPy·Pillow가 필요합니다. `tools/prepare_assets.py`는 외부 다운로드를 하지 않습니다. 지구 원본 파일을 지정하지 않으면 패키지의 지구 이미지를 사용합니다.

Python Playwright와 Chromium을 설치한 개발 환경에서는:

```sh
python tests/release_browser.py
```

실제 검증 범위와 GPU/직접 파일 접근 제한은 `docs/QA.md`와 `docs/release-browser-v0.06.json`을 확인하세요. 이전 버전의 검증 파일은 이름에 해당 버전이 표시된 보관 기록입니다.
