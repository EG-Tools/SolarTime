# Solar Time

**Life User • Solar Time v0.40 • Lyrikey@Naver.com**

실제 기기 시각으로 움직이는 감상용 태양계 시계입니다. 관측·항법용 정밀 천문력이 아닙니다.

## v0.40 변경

- 태양 코로나와 홍염의 프레임별 합성을 GPU로 옮겨 CPU 캔버스 작업을 줄였습니다.
- 웹과 로컬 실행본 모두 선택한 언어와 화면에 필요한 해상도만 Cloudflare에서 불러옵니다.
- 궤도 밝기 최대치를 50% 높이고 `index.html` 로컬 직접 실행을 복구했습니다.
- 불필요한 대용량 단독 HTML 생성과 중복 정적 에셋 배포를 제거했습니다.

## v0.39 변경

- 궤도 좌표를 GPU 정적 버퍼에 보관하고 카메라 투영을 셰이더에서 처리해 프레임별 CPU 계산과 업로드를 줄였습니다.
- 언어, 음악, 로컬 저장, 공통 팝업 동작을 독립 모듈로 분리하고 두 스타일시트를 하나로 통합했습니다.
- 우측의 기본시점·휠 작동방식 버튼과 상단의 배경음악·언어 변경 버튼 순서를 바꿨습니다.

## v0.38 변경

- 도움말의 업데이트 내역을 접이식으로 바꾸고, 이전·다음 화살표로 과거 버전을 볼 수 있게 했습니다.

- 달과 수성의 고해상도 사진 위에 중복되던 합성 요철을 제거해 분화구 음영이 과장되지 않게 했습니다.

## v0.35 변경

- 천왕성·해왕성처럼 본래 표면 특징이 적은 행성은 가짜 선명도를 더하지 않고 원본 해상도를 정확히 표시합니다.

## v0.34 변경

## 실행

로컬 개발 화면과 GitHub Pages의 온라인 화면은 루트 `index.html`을 사용합니다. 공개 주소는 `https://solartime.app/`이며, 기존 `https://eg-tools.github.io/SolarTime/` 주소도 GitHub Pages 원본으로 유지됩니다. HTML·CSS·JavaScript는 GitHub Pages가 전송하고, 음악과 해상도별 재질은 Cloudflare가 전송합니다.

로컬 실행은 루트의 `index.html` 또는 바탕 화면 바로가기를 사용합니다. 웹과 동일하게 Cloudflare의 언어·재질·음악을 사용하므로 인터넷 연결이 필요합니다.

## 배포와 대용량 미디어

- `npm run build:cloudflare`: 가벼운 코드·UI 배포 폴더를 준비합니다.
- `npm run publish:media`: 미디어가 변경됐을 때만 해상도별 파일과 검증용 묶음을 `solar-time-media` R2 버킷에 올립니다.
- `npm run fetch:assets`: 새로 받은 저장소에서 R2의 검증된 미디어 묶음을 내려받아 로컬 원본을 복원합니다.
- `npm run build:git`: GitHub 배포용 코드·UI 폴더를 준비합니다.
- `npm run deploy:cloudflare`: 로컬 원본으로 정적 폴더를 만든 뒤 Worker를 배포합니다. R2를 다시 업로드하지 않습니다.

일반 코드 배포는 이전과 같이 `main` 브랜치에 올리면 GitHub Pages가 루트에서 자동 배포합니다. 대용량 원본과 음악은 Git에서 제외되므로 미디어가 바뀐 경우에만 먼저 `npm run publish:media`를 실행합니다.

재질 주소에는 파일 내용의 해시가 들어가므로 내용이 바뀌지 않은 파일은 새 버전에서도 같은 객체를 재사용합니다. 웹과 로컬 실행본 모두 화면 크기에 맞는 해상도만 요청합니다. 원본 복원용 R2 묶음은 SHA-256을 확인한 뒤에만 사용합니다.

## 조작

좌클릭 드래그: 전 방향 시점 회전. 가운데 버튼 드래그: 상하좌우 ±80%. 우측 `줌/이동`: 휠·+/− 작동 방식 전환. 천체 더블클릭·가까이 보기: 추적. 0: 기본 시점. 1·2·3: 방식까지 포함한 저장 시점. H: 감상 모드. F: 전체 화면. ESC: 감상 → 전체 화면 → 팝업/패널 순서. Space: 정지/재생. R: 실제 시간.

## 배속

시간: 1분~24시간 / 초, 일: 1~365일 / 초, 년: 1~20년 / 초. 단위 버튼은 시간 → 일 → 년 순서로 순환합니다.

## 출처

기존 재질 출처와 이용 조건은 `assets/CREDITS.md`를 따릅니다. 현재 우주 배경은 사용자가 제공한 4096×2048 WebP를 유지합니다.
