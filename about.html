EVERY MOMENT, IN ORBIT

Explore time as a moving solar system.

Solar Time is an original interactive web experience that combines a real-time clock, a navigable solar-system model, time travel, planetary information, and ambient music in one cinematic view.

Solar Time은 현재 시각과 태양계의 움직임을 하나의 화면에서 감상하고 탐색할 수 있도록 Life User가 제작한 인터랙티브 태양계 시계입니다. 단순한 배경화면이 아니라 천체를 직접 선택하고, 시간을 이동하고, 궤도와 자전을 관찰할 수 있는 교육·감상용 시각화입니다.

Live orbital view

The planets, Moon, and Europa are positioned from the app's astronomical model at the selected simulation time. Playback can run from real time to accelerated years.

Interactive camera

Rotate, pan, zoom, follow a body, save camera presets, or compare the normal overview with the actual-size mode.

Planetary detail

Each body includes concise information about composition, temperature, gravity, orbital period, rotation, and visual scale controls.

Events and atmosphere

Explore eclipse events and multi-planet alignments, then switch to a minimal viewing mode with optional ambient music.

How the model is built

Solar Time uses layered astronomical calculations. Modern-era planet positions use higher-accuracy formulae, while distant dates use bounded long-term approximations. The Moon, Europa, and Pluto have dedicated models. Visual size and distance are adjusted in the default overview so that all major bodies remain understandable on one screen; actual-size mode removes those display adjustments where practical.

The visualization is intended for education, exploration, and artistic appreciation. It is not a substitute for an observatory ephemeris, navigation system, mission-planning tool, or safety-critical prediction service. Event dates and visual alignments should be confirmed with an authoritative astronomical source when precision matters.
