별빛과 함께 흐르는 시간

위쪽 시계는 실제 기기 시각입니다. 아래 재생 속도를 바꾸어도 시계는 실제 시간을 유지하고, 태양계의 시뮬레이션 날짜만 빨라집니다.

실제 시간과 배속

실제 공전은 매우 느립니다. 1일 / 초를 누르면 1초에 하루만큼 움직입니다. 1년 / 초에서는 바깥 행성의 움직임도 보입니다. 모든 행성에 같은 시간 배율을 적용하므로 상대적인 공전 속도는 유지됩니다.

일시정지는 공전과 자전, 별·태양 효과를 멈춥니다. 실제 시간 모드에서 재개하면 현재 시각으로 다시 맞춥니다. 날짜를 선택하면 해당 시각에서 일시정지합니다.

v0.16 · 중심 고정 카메라

천체 추적은 이전 팬 위치를 끌고 가지 않고 화면 정중앙으로 부드럽게 수렴합니다. 추적 대상을 바꿀 때도 중간에 줌 1×를 거치지 않고 두 천체의 월드 위치를 직접 블렌딩하여 경로가 끊기지 않습니다. 휠·확대 버튼·각도·드래그도 같은 카메라 소유자에서 이어집니다.

휠 확대는 더 이상 숨은 추적 대상을 만들지 않습니다. 좌·우 자동 회전을 시작할 때 화면이 팬되어 있으면 먼저 중앙으로 짧게 복귀한 뒤 회전하므로 확대·축소처럼 보이는 비정상 반경을 제거했습니다. «한국 보기»는 지구를 약 224×까지 확대해 한국을 더 크게 관찰합니다.

1·2·3(숫자패드 포함)은 감상 모드, 전체 화면, 버튼 포커스, 열린 팝업에서도 저장 시점을 불러옵니다. 입력란에서는 숫자 입력도 그대로 허용합니다. Ctrl·Alt·Meta 조합은 브라우저에 남깁니다. 숨겨진 달·명왕성 시점은 해당 천체를 다시 표시합니다.

ESC는 감상 모드 → 전체 화면 → 팝업·패널 순서로 한 번에 하나만 해제합니다. 전체 화면+감상 모드에서는 첫 ESC로 감상 모드만 해제하고 두 번째로 전체 화면을 종료합니다. F는 전체 화면만 켜고 끕니다.

두 단계 ESC는 브라우저의 키보드 잠금 지원·허용이 필요합니다. 권한이 없으면 브라우저가 전체 화면 종료를 우선할 수 있습니다. ESC를 길게 누르는 브라우저의 강제 탈출 기능은 유지됩니다. F11이나 운영체제 창 최대화는 앱의 F 전체 화면과 별개입니다.

확대 관찰

드래그와 각도 설정으로 위쪽 90°부터 아래쪽 −90°까지 관찰합니다. 휠·+/−·두 손가락으로 최대 256배까지 확대합니다. 더블클릭은 이전보다 큰 크기로 추적을 시작합니다. 추가 확대는 최대 256배까지 가능하며, 추적 대상의 최대 지름은 화면 짧은 변의 220%입니다. 기존 저장 시점의 64배 이하 크기는 그대로 유지됩니다. 천체를 더블클릭하거나 천체 정보의 «가까이 보기»를 누르면 해당 천체를 중심에 두고 따라갑니다. 0 또는 기본 시점 버튼으로 전체 태양계 구도로 돌아옵니다. 기본 구도는 v0.03보다 화면 높이의 5%만큼 위로 올렸습니다. 마우스 가운데 버튼을 누르고 드래그하면 기본 위치에서 상하좌우 각각 화면의 20%까지 상하좌우 이동합니다. 0 또는 기본 시점 버튼으로 이동량도 초기화합니다. 행성 표시는 거리 축척과 별개로 확대됩니다.

천체 이름은 기본적으로 각 천체 아래에 고정됩니다. 설정에서 «이름 겹침 자동 정리»를 켰을 때만 겹침을 피해 부드럽게 이동합니다. 달의 표시 궤도는 지구 크기와 분리하여 이전 버전보다 약 33% 줄였습니다.

태양 주변 샤인의 변화 속도는 v0.06의 4배입니다. 테두리 물결과 튀어 오르는 홍염은 제거했습니다. 태양의 실제 자전, 행성 공전, 별 반짝임은 이 배율의 영향을 받지 않습니다.

자전과 감상 모드

지구의 표시 크기를 기존보다 1.5배 키웠습니다. 자전은 각 천체의 실제 항성 주기를 사용합니다. 지구는 약 23시간 56분 4초에 한 바퀴 돌며, 금성·천왕성·명왕성은 역행 자전합니다. 별도의 감상용 자전 가속은 없습니다. 공전을 배속하면 자전에도 같은 배율을 적용하고, 일시정지·날짜 이동도 함께 반영합니다.

자전 주기는 대표 측정값을 사용합니다. 가스 행성의 구름은 위도에 따라 다르게 움직일 수 있으며, 태양의 차등 자전은 단일 대표 주기로 단순화했습니다. 지구는 간단한 항성시 계산으로 한국의 낮·밤을 표현합니다. 다른 천체의 기준 경도·자전축 방향·목성의 대적점 경도는 실시간 관측과 맞추지 않은 표현입니다.

감상 모드에서는 마우스 이동·클릭 또는 화면 터치로 오른쪽 시점 조작부 전체와 감상 모드 토글이 나타납니다. 약 1.8초간 조작하지 않으면 조작부와 커서가 다시 숨겨집니다. 드래그 중에는 숨기지 않습니다. 기본 시점은 감상 모드를 유지한 채 전체 태양계로 돌아가고, 모드 전환은 일반 화면을 표시합니다.

로컬 보정과 가벼운 루프

자전축 방향은 고정하고, 자전·공전 주기를 초 단위 소수점 둘째 자리로 저장합니다. 기준 시각에서 경과한 시간으로 회전각을 바로 계산하여 프레임 누락에 따라 느려지지 않습니다. 앱을 실행할 때마다 기기 시각으로 기준 위치와 자전 위상을 보정합니다. 실행을 계속하는 동안에는 매년 1월 1일 00:00 UTC에도 기준을 갱신합니다. 계산에는 인터넷이나 서버 응답이 필요하지 않습니다.

시작 위치는 간단한 근사 궤도 계산입니다. 관측용 위치를 보장하지 않으며 연간 오차를 모든 천체에 대해 «몇 초»라고 보장하지도 않습니다. 높은 배속에서는 빠른 자전이 프레임 사이에 여러 번 돌아 정지·역회전처럼 보일 수 있습니다.

이미지 자료와 오프라인 저장

지구는 기존 NASA Blue Marble 재질을 유지합니다. 그 외 천체는 최초 온라인 실행 시 Solar System Scope / INOVE · CC BY 4.0의 구면용 재질과 NASA SVS CGI Moon Kit · LRO/LROC · Ernie Wright의 달 지도를 받습니다. 구름·대적반 위치와 색은 대표적인 묘사이며 현재 관측 영상이 아닙니다.

성공한 이미지는 이 브라우저에 저장합니다. 네트워크나 저장 기능이 차단되면 내장 재질을 유지하며 화면 설정에서 상태를 확인할 수 있습니다. ‘이미지 포함 HTML 저장’으로 현재 받은 지도를 파일에 포함하면 다른 기기에서도 오프라인으로 볼 수 있습니다. 궤도·자전은 서버 없이 계산하고 이미지 수신을 기다리지 않습니다.

정확도와 표현 범위

실행 시 8개 행성 기준 위치는 NASA JPL 평균 궤도 요소로 계산하고, 이후에는 그 궤도에서 고정된 주기로 반복합니다. 지구는 지구·달 질량중심으로 근사하며 UTC와 TDB의 차이를 생략합니다. 달은 평균 항성 주기를 이용한 원 궤도, 명왕성은 고정된 평균 타원 궤도입니다.

행성과 궤도선은 동일한 좌표식을 사용합니다. 거리와 크기는 보기 편하게 조정하고, 넓은 화면에서는 궤도 투영을 가로로 확장합니다. 표면·자전축의 절대 방향·별·태양 효과는 예술적 표현입니다. 고리는 표면과 같은 자전축의 적도면에 놓고 카메라에 따라 입체 투영합니다. 실제 관측, 월식·일식 예측에는 사용할 수 없습니다. 날짜 범위는 1800–2999년이며 끝에 도달하면 정지합니다.

달의 공전과 위상은 NASA의 달 설명, 명왕성의 개략 주기는 NASA 명왕성 자료를 참고했습니다.

360° 우주와 표면

은하·성운·별은 한 장의 화면 배경이 아니라 시야 전체를 둘러싼 구면입니다. 카메라 회전에 반응하고 1초에 약 0.22°씩 천천히 회전합니다. 이는 실제 은하 회전이 아닌 감상용 시야 움직임입니다. 확대 시 배경은 같이 커지지 않습니다. 설정에서 회전·혜성을 각각 끌 수 있습니다.

태양의 테두리 물결·홍염은 제거하고 샤인만 남겼습니다. 달과 행성은 폴리곤 구가 아닌 픽셀 단위의 구면 셰이더로 그립니다. 한국 보기와 붉은 소용돌이 보기는 카메라만 돌리며 자전 속도를 바꾸지 않습니다. 축척을 조정한 화면에서 달과 태양이 겹치는 것은 실제 일식 판정이 아닙니다.

지구 영상: NASA Visible Earth / Blue Marble Next Generation (Basemap 배포본, 해상도·색상 조정). 구름은 실시간 기상 자료가 아닙니다. 기타 표면·별·은하 영상: Life User / Solar Time 절차적 재질.

추적 중인 천체 이름과 전체 보기 카드는 표시하지 않습니다. H 또는 Esc로 감상 모드를 종료하고 0으로 기본 시점에 복귀합니다. 터치 기기에서는 한 번 터치하면 두 조작 버튼이 나타나며, 세 손가락으로 터치해 바로 종료할 수도 있습니다.

카메라 시점 1 · 2 · 3

오른쪽 기본 시점 아이콘 아래의 숫자를 좌클릭하거나 우클릭하면 동일한 적용 / 저장 / 삭제 / 취소 팝업이 마우스 위치에 열립니다. 적용은 저장된 시점으로 부드럽게 이동하고, 저장은 현재 각도·확대·이동·추적 대상을 해당 번호에 보관하거나 덮어씁니다. 삭제는 그 번호만 지웁니다. 빈 번호는 적용·삭제가 비활성화됩니다.

키보드 1·2·3은 저장된 시점을 바로 적용합니다. 다른 천체 사이에서는 전체 구도를 거쳐 부드럽게 이동합니다. 취소·Esc·창 밖 클릭은 저장 내용을 바꾸지 않습니다. 감상 모드에서도 팝업을 사용할 수 있고, 날짜·재생 속도는 그대로 유지됩니다. 시점은 이 브라우저에 저장되며 저장이 차단되면 현재 창에서만 유지됩니다.

카메라 자동 회전

오른쪽 조작부는 확대 · 축소 · 기본 시점 · 1 · 2 · 3 · 좌회전 · 우회전 · 감상 모드 순서입니다. 회전 아이콘을 누르면 현재 각도와 확대·이동·추적 대상을 유지하며 초당 2°씩 수평으로 회전합니다. 같은 버튼을 다시 누르면 정지하고, 반대 버튼을 누르면 방향을 바꿉니다. 드래그·휠·기본 시점·번호 시점 불러오기는 자동 회전을 멈춥니다. 공전 배속·일시정지는 카메라 속도를 바꾸지 않습니다.

감상 모드에서는 마우스 이동·클릭·터치 시 동일한 오른쪽 조작부 전체와 모드 전환 아이콘을 표시합니다. 약 1.8초 동안 조작하지 않으면 다시 숨깁니다. 자동 회전 중에도 숨김은 유지하며, 카메라 저장·삭제 확인창을 띄운 동안에는 조작부가 사라지지 않습니다.

시계의 초 표시는 기본 OFF입니다. 화면 설정의 «시계 초 표시»를 켜면 초 숫자와 구분자가 함께 표시됩니다. 숫자 표시 여부는 행성 시간 계산에 영향을 주지 않습니다.
