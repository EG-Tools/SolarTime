# iPhone 홈 화면 실행 — 실기 확인

자동 검증은 Chromium·Firefox·데스크톱 WebKit에서 수행합니다. 아래 항목은 실제 iPhone에서 별도 확인해야 하며, 자동 검사 통과를 실기 확인 완료로 간주하지 않습니다.

- [ ] iPhone 모델·iOS 버전·검증한 배포 버전과 날짜를 기록합니다.
- [ ] Safari에서 접속하고 홈 화면에 추가한 뒤 독립 창으로 실행합니다.
- [ ] 사용자 클릭 후 기본 알람과 사용자 음원, 배경 음악의 시작·정지·음량을 확인합니다.
- [ ] 알람 예약 후 화면 잠금·앱 전환·복귀 시 상태와 소리를 확인합니다. OS가 백그라운드 실행을 제한하는 경우를 기록합니다.
- [ ] 알람이 울리는 중 새 버전이 감지되어도 재생 중 화면을 강제로 새로고침하지 않는지 확인합니다.
- [ ] 예약·취소·변경 후 새로고침과 재실행, Safari와 홈 화면 실행 간 저장소 차이를 확인합니다.
- [ ] 세로·가로 전환, 화면 복귀, 안전 영역과 타이머·언어 카드 배치를 확인합니다.
- [ ] 네트워크 단절 후 재연결 시 선택 언어가 복구되고 조작이 가능한지 확인합니다.

현재 상태: 실기 확인 미실시. 실제 Windows 종료 명령은 브라우저 자동 테스트에서 실행하지 않습니다.
