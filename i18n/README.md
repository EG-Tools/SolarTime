# SolarTime 번역 관리

## 수정할 원본

- `locales/<언어코드>.json`: `ui`, `timer`, `bodies`, `phases`별 실제 번역 원본.
- `config.json`: 지원 언어, 서식, 자동 언어 라벨, 브라우저 언어 인식 규칙.
- `releases.json`: 변경 내역의 기존 원문과 번역. 표시용 JS는 여기서 생성한다.
- `context.json`: 오해하기 쉬운 문구의 사용 맥락과 용어 기준.
- `legacy-allowlist.json`: 이전 버전에 이미 있던 영어 대체 문구와 문법 변수 차이의 명시적 목록. 번역 완료 목록이 아니다.

`src/locales/*.json`, `src/language-data.js`의 GENERATED 블록, `src/release-notes.js`의 GENERATED 블록은 **생성 결과**다. 이곳만 직접 수정하면 자동검사와 양쪽 사이트 빌드가 실패한다. 원본에서 변경한 뒤 다시 생성한다.

지역 정보는 기존 `src/app.js`의 `LANG_META`와 `REGIONS`를 유지한다. 국가 48개와 번역 묶음 13개는 별개다. 같은 영어·스페인어 등을 사용하는 나라에 번역 파일을 복제하지 않는다.

## 새 기능 문구를 추가할 때

1. 사용 위치와 의미를 확인하고 영어 기준 문구와 한국어 문구를 먼저 확정한다. 실행 코드와 HTML은 문구 키를 참조한다.
2. `ui` 또는 `timer` 중 **한 곳에만** 같은 키를 등록한다. 기준 언어는 `en`이다. 같은 단어라도 창 닫기, 알람 정지, PC 종료처럼 의미가 다르면 합치지 않는다.
3. `npm run diff:i18n -- --base=HEAD`로 변경된 원문·번역 및 재검토가 필요한 언어를 확인한다. 이미 커밋했다면 PR 기준 커밋/브랜치를 지정한다. 생성 파일은 번역 변경분 검토 대상에서 제외된다.
4. 새 키를 나머지 언어 원본에 번역하고 `{time}`, `{remaining}`, `{code}` 같은 변수 **이름**을 보존한다. 어순과 같은 변수의 반복 횟수는 언어마다 달라도 된다.
5. `npm run build:i18n`을 실행한다. 원본 검사, 공개 언어 파일·예비 영어 문구·자동 라벨·변경 내역 생성, 내용 기반 캐시 키 갱신이 이어진다.
6. `npm test`와 기존 브라우저 검사·배포 절차를 따른다. AI 초안과 자동검사 통과가 원어민 검수를 의미하지는 않는다.

문구의 의미가 바뀌면 기존 번역도 재검토한다. `diff:i18n`은 영어가 바뀌었지만 대상 언어가 그대로인 키를 표시하지만 번역의 정확성을 자동으로 보증하지 않는다. 이 도구는 외부 번역 API를 호출하지 않는다.

## 생성·검사·보고서

```text
npm run build:i18n                         # 원본 검사 + 생성 + 캐시 갱신
npm run check:i18n                         # 원본/생성 파일 일치 검사
npm run report:i18n                        # 기존 영어 대체 문구와 변수 차이 JSON
npm run diff:i18n -- --base=HEAD            # 아직 커밋하지 않은 원본 변경분
node tools/i18n.cjs --strict               # 기존 대체 문구까지 모두 없을 때만 성공
```

일반 검사도 **새 누락, 빈 문구, 잘못된 변수, 알 수 없는 키, 중복 키, 잘못된 생성 결과**를 차단한다. 의도적으로 빈 선택적 AU 주석과 언어 공통 `SHA-256` 표기는 config에 별도로 선언한다.

v0.61에서 이어진 타이머의 영어 대체 항목은 언어·키 조합으로 133개다. 과거 변경 내역은 언어·버전 조합으로 116개가 영어를 사용한다. 서로 다른 단위이므로 두 수를 '미번역 문장 수'로 합산하지 않는다. 네 언어의 기존 지구 안내문에는 영어에 없는 고도/낮밤 변수가 있으며, 기존 문자열의 해시를 잠가 화면 내용을 유지한다. 이 목록은 기존 상태를 숨기지 않고 드러내기 위한 것이다.

기존 미번역을 실제로 번역하면 해당 원본을 추가하고 해당 허용 항목을 제거한다. 영어 원문을 바꾸면 기록된 원문 해시가 달라져 허용이 자동 연장되지 않는다. 새 번역 누락을 통과시키려고 이 목록을 무조건 늘리거나 해시를 일괄 갱신하지 않는다.

## 실행 시 규칙

- 앱은 선택 언어 한 묶음을 요청하고, 성공한 결과와 진행 중인 요청을 언어별로 공유한다.
- UI·타이머·천체 설명·달 위상은 한 묶음에서 읽는다. 누락되거나 잘못된 값은 생성된 영어 기본값으로 보완한다. 영어 기본값은 별도 네트워크 요청 없이 이용 가능하다.
- 결과는 불변 객체이며 앱에서 번역을 다시 덮어쓰지 않는다. 어떤 언어를 먼저 열었는지에 따라 예비 문구가 한국어로 바뀌지 않는다.
- 기존 `zht` 파일 전체가 404일 때 `chn`으로 시도하는 과거 배포 호환 분기는 유지한다. 개별 문구 누락의 일반 기본값은 영어다.
- 직접 `file://` 실행의 기존 보완 라벨은 동일 원본에서 생성한다. 직접 실행도 공개 서버의 언어 파일을 사용하므로 인터넷 연결이 필요한 기존 조건은 유지된다.
- 알 수 없는 프로그램 키의 최종 식별자 표시는 개발 오류다. 검사로 배포 전에 잡으며, 이를 정상 번역이라고 취급하지 않는다.

## 범위와 유지 사항

HTML의 로딩 전 기본 마크업, 별도의 소개/개인정보/이용약관 문서, 국가·대표 도시 고유명, 천문 엔진 내부의 호환용 식별/설명 메타데이터는 일반 UI 번역과 구분한다. 천체 카드의 실제 표시 문구는 이제 모두 언어 원본을 사용한다. 천문 엔진 계산과 수치는 수정하지 않았다.

알람·음악 동작/볼륨, Windows 도우미, 48개 지역·시간대·고정 AUTO 메뉴, 기존 디자인은 유지한다. 보류된 17·18·19·21·22·24, 미승인 25·26은 이번 정리 범위가 아니다. 무거운 다국어 라이브러리나 외부 유료 서비스를 추가하지 않는다.
